# Instructions for theory maintenance

Read this folder's README before every edit batch. It is the canonical format spec.
Blockquotes contain the curator's words only. Literature and superseded claims never go
in quote blocks. Preserve identifiers. Fold corrections into the relevant section.
Revisit a table's afterword in the same edit and use the fixed Confidence vocabulary.
Do not add dated change narratives to afterwords. Follow the README's dash discipline.
Structural changes to theory require the curator's direction; routine result rows follow
the grind contract in the repository AGENTS.md.
