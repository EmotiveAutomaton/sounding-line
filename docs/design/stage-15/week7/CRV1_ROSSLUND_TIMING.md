# CRV1 · timing during separate picture-book readings

The curator approved a separate comparison on November 26. Rosslund et al. recorded each parent reading to an infant and an adult in separate blocks. Use the two version-1 timing tables, with source hashes in the archive receipt. These observations address timing during elicited reading. The original question about switching addressees during a single recording and the question about comforting an adult remain open.

For each timing measure, form an infant-directed minus adult-directed difference within a parent and study session. Use the mean duration of observed target vowels in milliseconds for the first measure. For the second, take the mean of the authors’ phrase-level articulation rates, calculated as 1,000 times the syllable count divided by phonation time in milliseconds. The denominator excludes pauses. Give sessions equal weight within each parent and then give each parent equal weight. Count complete pairs, parents, unmatched sessions and missing inputs separately for each measure. A parent can contribute to one measure when the other is unavailable.

Retain provider observations with a parent, session, registered speech type and a finite positive measured duration or phonation time. A syllable count must be a nonnegative whole number. Unexpected speech types stop the reader. Exclude missing required values and count them. Use the earlier CRV1 support rule of at least 20 paired people for an interval. Draw 2,000 whole parents at the existing CRV1 seed and use the 2.5th and 97.5th percentiles. Record signed differences, intervals and units. A fresh process repeats the complete read and fit.

Differences can reflect how a parent performed the book in each block and which target vowels or phrases were available. Parents in the same household can be related across clusters. No comparison with the pitch sample or generalization to spontaneous conversations is registered. File the aggregate return internally with the design and source attribution.
