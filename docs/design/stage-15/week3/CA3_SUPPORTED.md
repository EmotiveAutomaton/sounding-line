# CA3 supported-input comparison

On October 25 the curator approved: “Prepare the supported subset; retain the
full-population gap.” This separately labeled variant keeps the original CA3
question and all 2,979 fixed annotators. Its evaluation population is the 836
annotators with both unexplained comparisons and sampled explanation targets.

This is a change of population, not evidence against the original hypothesis.
It cannot establish a full-population effect or represent annotators who did not
provide both kinds of record. The original input artifacts stay immutable.

## Preparation contract

`week3_alignment_values_supported` authenticates the completed original census,
reconstructs it from the complete CA1 and VAL source inputs, and selects every
annotator with both required input types. It uses no labels, features, fitted
directions or performance to choose recipients. Within each included annotator,
all original unexplained fit comparisons and all sampled held-out targets stay.
Every explained comparison stays excluded from fitting, including explanations
that were not sampled for labeling. The complete original census, unchanged
recipient records and explicit inclusion dispositions are retained privately.

Known-answer checks cover all four combinations of input presence, forged support,
overlap, census drift, immutable reentry, a separate-process reconstruction and
resealed false source records. Native execution must reproduce the complete
fixture before corpus preparation. All counts are frozen before either run.

The original 600 CPU-second source allowance includes its prior 20.046875 CPU
seconds. Reserve 120 additional CPU seconds for preparatory checks, then count
native execution and full preparation plus their independent replays against the
same allowance. No new allowance or scientific execution is granted here.

## Remaining comparison gates

The original two-hour CA3 comparison ceiling, individual-minus-country primary,
population comparator, leave-annotator-out centered value prototypes, fixed
prevalence rule, annotator uncertainty and empirical controls remain. This
preparation does not change the full VAL label sample or discard the original
prototype source pool. Any later model admission must explicitly freeze its donor
