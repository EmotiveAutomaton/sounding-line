# WA0 and approved WA0.h1: identification references

The Week 3 packet commissions a new control audit over the complete saved PMAP,
EV3 and matched GEN1 inputs. The curator approved a separate corrected reference
on October 25 after the literal proposed reference failed a known-answer check:
"Build the corrected control; retain original diagnostic."

## The control defect and its disposition

For a balanced shared-prompt population with stable person vector `x_w`, the
literal leave-writer-out prompt mean is `(sum(x)-x_w)/(N-1)`. Across prompt halves
it is a stable negative fingerprint of the omitted person. An exact fixture
therefore identifies every writer from both the real vector and the purported
context-only vector. This is an instrument defect, not negative human evidence.
The literal WA0 implementation retains the requested draws and original pooled
audit; its badge licenses are structurally false. It cannot rescue or retract
the old person result merely by running to completion.

WA0.h1 fixes donor contamination through three writer roles. Sorted writer IDs
are shuffled once with seed 20261026 and assigned modulo three. In rotation `f`,
fold `f` supplies context means; both other folds supply the fixed gallery; only
fold `(f+1) mod 3` supplies scored probes. All rotations run. Each original
eligible writer is scored exactly once, with a gallery of roughly two thirds of
the eligible writers. The smaller galleries are explicit; this is not the old
full-gallery accuracy. Gallery writers are never bootstrap-resampled.

Calibration donors never belong to that rotation's probe or gallery. The same
context vector applies to every analysis session sharing a prompt. Prompt means
use available donor session features, with no fallback to a scored writer. Missing
fixed-gallery support is unsupported, not zero, and never causes a redraw or
successful-subset result. One shared null assignment shuffles writer labels within
prompt and frozen writer-role fold, and is reused across all rotations. This
preserves each prompt's writer-label counts and the donor-role membership while
retaining dependence between overlapping galleries. Donor feature means stay
fixed. Every permutation rebuilds the whole-prompt chronology split and profiles.
This is a conditional null for the approved three-role design, distinct from the
literal diagnostic's unrestricted within-prompt null.

## Matched measurement in every arm

PMAP and GEN1 originally pooled counts or took medians over all events. Averaging
session-level prompt means only in the context arm would change the ruler between
arms. The declared `WA0.session-summary` variant instead computes the original
feature vector separately in each session, then takes finite-feature unweighted
session means in all real, context and permuted halves. EV3 already used session
means. The old exact pooled PMAP and GEN1 profiles are reproduced in a separate
audit column and kept unchanged. Passing the new variant does not retrospectively
validate the old pooled estimand.

Whole prompts alternate between halves by their first timestamp within writer,
as in PMAP. Probe and gallery never share that writer's prompt or session. Fixed
original PMAP channel rosters are retained, including the common lean/style
roster; matched GEN1 retains all 24 writers. Any missing complete support is
reported explicitly. Constant galleries tie fractionally, without ID tie breaks.
Scaling and partial-feature imputation use the gallery half only.

The new final-document style variant uses the frozen PMAP word/punctuation
dictionary and tokenization on complete final documents, including prompt and
accepted text. Accepted-character share means surviving accepted codepoints
divided by all final-document codepoints, including prompt characters. This
denominator and the full provenance partition are checked. Residualized final
style and EV3 habits fit each feature's linear accepted-share nuisance on
analysis-gallery sessions only, then apply those coefficients to both analysis
halves and independent context donors. Every null draw refits that nuisance on
its rebuilt gallery half. There is no identity-based feature selection.

The primary remains residualized final-document EV3 habits. Each variant needs
both the one-sided 1,000-draw empirical writer-label probability below 0.05 and
the 2,000-draw paired probe-writer interval for real minus context wholly above
zero. A page badge additionally needs both raw and residualized variants to pass.
Typed fragments license no page badge independently. Process features remain
limited to process records. All probabilities are descriptive.

## GEN1.ic and the arithmetic correction

Ten versus twelve correct writers does not establish two discordant writers.
The actual paired correctness table is retained, and exact two-sided McNemar
probability is computed only when correctness is binary. Fractional gallery ties
remain explicit and do not become invented binary labels. Whole-writer genre
labels are swapped 1,000 times; every swap rebuilds profiles and the same fixed
gallery design. No comparison is licensed unless both genres pass their own
identification controls.

The planning curve enumerates exact McNemar rejection probability over per-genre
accuracies from 0.40 through 0.90 in 0.05 increments, holding the empirical binary
phi correlation fixed. Infeasible joint-distribution cells are reported rather
than clipped. Zero-variance correctness cannot identify dependence and makes
this power curve unsupported. The minimum feasible grid difference with at least
80% power is reported when one exists. No universal 31-percentage-point bound is
inferred from marginal counts. This is fixed-gallery planning sensitivity, not
a population-independent threshold or evidence for the broader play-frame claim.

## Sources, output and execution

`week3_identification_inputs` consumes four completed, independently verified
sources: PMAP-recovery, EV3 habit input, full EV final-document input, and verified
GEN1 matched features. It retains all 1,399 corpus sessions and all 990 matched
GEN1 sessions. Completed output bytes and source plans are authenticated; identities
are joined exactly. The source output contains session vectors and original pooled
profiles, not a scientific verdict.

`week3_identification` runs the literal diagnostic. The separately approved
`week3_identification_crossfit` runs WA0.h1. Both reconstruct every draw during
fresh verification, preserve aggregate reports and private hashed-writer detail,
and refuse changed bindings. `week3_identification_timing` first runs one tenth of
both complete designs and fresh replay, discards all scientific scores and emits
only timing/work counts. Its measured execute-plus-verify projection, preparation
charge and pilot charge must fit the single shared three-CPU-hour WA0 ceiling.

Constructed checks cover exact null, prompt-only null, the literal reference's
negative fingerprint, corrected persistent-person recovery, reversed galleries,
donor isolation, immutable input population, missing context, accepted-share
nuisance removal without probe fitting, Unicode provenance, paired-table
arithmetic, feasible power, complete execute/verify and corruption refusal.
These checks validate the instrument; corpus results remain unrun until the
owner dispatches the versioned plans under the counted runtime.
