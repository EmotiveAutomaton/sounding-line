# T4 immutable text representations

**Case and check.** Bind the complete canonical menu source, the complete P6 typed-history index and the already completed CONTENT_V2 encoder identity and cache. Preserve every offered option, preceding visible sentence and typed-history sequence, with session/writer identity and source timestamps. Empty typed histories remain empty. Separate context and suggestion visibility keys; no target choice is consulted to select or encode text. Verify cached text/role digests and actual encoder agreement before admitting new representations.

Use the same pinned all-MiniLM-L6-v2 weights, float32 CPU, one numerical thread, CLS/SEP-inclusive masked mean pooling and unit normalization. Options and space-joined P6 typed-history sequences use the first 254 model tokens; the preceding sentence uses its last 254. Record the entire visibility scope, including truncation. Reuse an existing vector only for an exact matching text-and-role key from the authenticated CONTENT_V2 completion. New text is encoded in deterministic length-sorted batches of sixteen. Fresh verification re-encodes every new vector and compares at absolute tolerance 0.000002, with zero relative tolerance; repeat inputs and sixty-four cached anchors must pass the same check. Original byte checks remain separate and mandatory.

This pass prepares representations, not personal profiles or fitted choice models. Each history's source session and start/end clocks remain attached. A later consumer must enforce completion strictly before each target menu for own and population histories; the full cache itself includes every source session and is not a causal history selector. Source chronology, writer support, dismissal intercepts and model identifiability still require separate admission.

**Smaller route.** First run a measured encoder cost probe on 128 new texts at evenly spaced ranks of token length, preserving the complete source inventory. Forecast all new representations plus full independent re-encoding with a 1.5 margin. Charge source preparation, model loading, native tests and costing to T4's original one-hour account; reserve remaining model-fitting work. If the whole-card projection exceeds the single S4 doubling, freeze a whole-writer sample under amendment E before any model scoring. A cost probe is never scientific support.
