# DRIVE source and V3 opportunity census

Frozen before source outcomes, 5 November 2026. This is preparation for the
already commissioned DRIVE/V3 node; no new hypothesis or paid call is created.

**DESIGN CHECK.** LESSONS sections 2–5 read for this build. Under either the null
or an alternative, exact completed R2 records, complete provenance coverage and
immutable replay are required. Invalid source records remain exclusions. The
support rule can fail: fewer than 25 writers with at least 200 eligible sentence
occurrences in each session half cannot admit the planned V3 main comparison.
These are source opportunities, not successful model labels or scientific power.

**Case and check.** Use the completed, independently replayed R2 archive census,
all 1,445 sessions, with its original replay exclusions. Follow P5's existing
sentence policy: final surviving punctuation/newline-bounded segments (including
the trailing segment), eligible only if every nonspace character has typed
provenance. Do not concatenate disjoint typed spans around accepted text.
Mixed, prompt, accepted, accepted-edited and unknown spans remain explicit
exclusions. This source cannot speak for sentences deleted before the final
document, and does not pretend to census all produced sentences.

Each eligible item carries exactly its sentence and the immediately preceding
segment of that same final document, regardless of that predecessor's provenance.
There is no preceding context for the first segment. Private source joins retain
session, writer and offsets; a distinct payload projection contains only the two
text fields. Exact payload duplicates need one future API request but every
source occurrence remains in the support denominator. No labels, affect scores,
canonical choices or writer profiles are sent or computed in this stage.

Within each writer and genre, sort sessions by SHA-256 of the fixed seed
20261102 and session identity, then alternate them between halves. Freeze this
before inspecting counts. Also compute the split-independent necessary bound:
a writer with fewer than 400 eligible occurrences cannot supply 200 in each half
under any session partition. Report pooled and separate-genre counts. Neither
this bound nor passing source counts admits V3 without valid labels and the
three-role donor comparison, controls, uncertainty and complete cost admission.

**Smaller route.** A first 145-session source timing prefix precedes the complete
census. The full run requires a conservative measured execution plus fresh
verification forecast inside V3's original 3,600 CPU seconds, retaining at least
2,400 seconds for later calibration/analysis. Source cost is charged cumulatively,
including validation. No smaller support threshold or reduced label bank is
introduced if admission fails. Failure of the declared complete source case
cancels the corresponding DRIVE main batch as the packet requires; calibration
and other nodes remain separately governed by the approved campaign.

Known-answer checks cover Unicode provenance, immediate mixed-source context,
trailing segments, empty documents, exact coverage refusal, duplicate payloads
with retained occurrences, order-invariant halves and the support boundary.
The counted worker verifies the source projection afresh using an independent
per-codepoint provenance reconstruction and alternate segment assembly. Raw
text and writer-level counts remain in ignored private run directories. Only
aggregates enter reports. No new model, GPU use or external transfer occurs.
