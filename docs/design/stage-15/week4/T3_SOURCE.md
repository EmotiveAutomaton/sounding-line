# T3 source and dated-half support

This implements the commissioned T3 case check before library learning or any
compression outcome. It is preparatory, not a replacement for either sequence
channel in the packet. The event-token channel, donor and population matching,
merge learning, reuse and full ownership-reassignment reference remain required.

**Case and check.** Authenticate all 1,399 primary CoAuthor P6 records and the
already frozen 150-word dictionary. Use the completed final writer-typed spans
that P6 retains as training sequences, so accepted and prompt text cannot bridge
two typed spans. Keep line/provenance boundaries and split on sentence-ending
punctuation; count only words and replace words outside the fixed dictionary with
the same content placeholder. This is the final typed-text skeleton channel;
it is not the production-event sequence, and later-deleted words are not its
tokens. The event channel must retain its separate provenance and denominator.

Sort each writer's complete session roster by start time, then session identifier
for ties. The first floor(n/2) sessions form the training half; the remaining
sessions form evaluation. Empty sessions remain in the split. Require at least
2,000 skeleton words in each half for at least 25 writers. Also retain the stricter
leakage check that every training session ends before evaluation begins; overlap
is an explicit unsupported category, never silently repaired by shifting the cut.
Count the packet's token-only floor separately from this chronological check.
Keep all writers, both halves, prompt counts and genre counts in private support
records. No donor support or scientific effect is inferred from this source floor.

Known cases must reproduce exact boundaries, token counts, odd and even dated
splits, retained empty sessions, exact floor equality, chronology failures and
duplicate source rejection. A fresh native process replays all deterministic
outputs before corpus admission. The shared dictionary is transductive and fixed
before outcomes; library and unigram fitting must use training halves only.

**Smaller route.** Bound constructed validation to 60 CPU seconds and the complete
source replay to 240 CPU seconds, charged within T3's original 3,600-second ceiling.
The analogous complete typed-window source already measured 54.0625 CPU seconds;
a threefold source forecast leaves room for this simpler support pass. These
bounds do not admit compression or its thousand reassignment fits. Their complete
cost and constructed recovery must be measured separately. If the full card
exceeds its authorized cost route, apply amendment E's frozen whole-writer sample
with the same 25-writer/2,000-word floor, preserving the full-population gap.
