# PLANT: frozen goal allocation and initial calibration

Commission: Week 4 packet T6 and section 5; existing seven-node approval. This
implements the commissioned instrument, not a new hypothesis or a claim of novelty.

DESIGN CHECK: method LESSONS sections 3–5 reread November 5. Under either no
recoverable goal signal or successful goal realization, transport must preserve
the complete request, response and allocation. Format fails below 98 of 100.
The separate blind non-disclosure check fails below 45 of its fixed 50 items;
an invalid response in that sample fails that item's check. Neither gate proves
goal realization or reader accuracy. Missing coverage, changed pins, uncertain
submission or incomplete billing holds subsequent work; none means scientific null.

**Case and check.** T6 asks whether a reader recovers the goals assigned to a
generator. Enumerate 600 unique genre prompts, with 300 arguments and 300 stories.
Within each genre allocate 50 no-goal, 125 one-goal and 125 two-goal pieces. Freeze
all assignments, the twelve goal definitions and all prompts before generation.
Assigned goals are known instructions, not independently verified realized intent.
The initial format and non-disclosure calibration tests the interface first.

**Smaller route.** Count actual input tokens and reserve the fixed 700-token output
ceiling before each batch. No population reduction is authorized for the primary
600-piece allocation. If its full count does not fit the remaining 50-cent node
allowance, retain a cost hold. Local preparation, validation and eventual analysis
share T6's 1,800 CPU-second ceiling; reserve 120 seconds for this interface and
tests, record actual preparation CPU, and retain at least 1,500 for the consumer.

The implementation freezes twenty settings crossed with twenty decisions per
genre. A seed-20261102 digest order partitions those 400 prompts per genre into
300 main, 50 initial-calibration and 50 fresh-correction prompts. Goal allocation
uses a separate seed order within each partition. The main counts are exactly
100/250/250 for zero/one/two goals. Each calibration has 16/42/42. Single-goal
and two-goal allocations cycle over independently ordered goals/pairs; record
their actual marginals. No payload is a duplicate, and IDs are content digests.
None of the calibration prompts or pieces enters the main 600-piece analysis.

Twelve operational goals: earn trust in the narrator or speaker; encourage
caution before acting; honour inherited tradition; favour revising an established
practice; favour mutual assistance; protect independent choice; favour reconciliation;
favour accountability for consequences; encourage curiosity about the unfamiliar;
favour patience over immediate reward; encourage acknowledging uncertainty;
encourage acting despite fear. These are an analyst-built closed library for this
instrument, not a claim about the complete human goal hierarchy.

PLANT receives only this library, assigned codes and a genre prompt. No source
corpus, identities or profiles are read or sent. Each response is constrained JSON
with exactly one nonempty `piece` string. Prompt target is 180–240 words, with no
hard word-count rejection or clipping. Thinking is disabled. Whole messages must
have the exact commissioned model, normal end-turn, text-only content, unique JSON
keys and no suffix. A valid JSON prefix of a truncated message is invalid.

The initial 100-item batch is format-only until the owner completes the blind
check. Fifty goal-bearing calibration prompts are selected before generation,
25 per genre, by a separate content-digest order. The blind view supplies only a
fresh opaque ID and the complete piece, withholding assigned codes and prompts.
The check asks whether a piece explicitly announces its intended effect on the
reader or names its hidden writing instruction (including an equivalent direct
declaration); merely depicting an action or arguing for a practical choice is
not such an announcement. Save one judgment and evidence/reason per item before
unblinding. Invalid items remain in the fifty and count as failures. These are
agent judgments, not curator labels or independently known semantic truth.

The approved one prompt correction, if needed, uses the separate fresh 100-item
bank and a separately frozen version; a second failure stops PLANT. This module
has no correction or main dispatch entry point. Main preparation and admission
follow complete calibration write-through and cost counting. REV remains an
independent approved node whose format validation and T6 reader are still needed.

All request/response bytes and malformed rows are retained privately. Submission
is reserved through the unchanged Week 4/gear3 ledger before POST, with no retry
after unknown delivery. A finite retrieval-only monitor registers completion and
failure with the existing watcher. Complete replay and usage settlement precede
any next node. Public receipts contain aggregate diagnostics only; scientific
interpretation waits for the final Week 4 packet.
