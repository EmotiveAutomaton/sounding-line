# T4 strictly earlier text features

**Case and check.** The completed menu and representation sources retain every session's start and end clocks. Admit a history only when its entire session ended strictly before the target menu opened; exclude the target writer from the population prototype. Equal timestamps do not count as earlier. No target choice selects history or representations. Test this rule on known vectors, including future, concurrent, same-writer and empty histories, before human feature preparation. Whole-source support must still leave twenty eligible menus in each temporal half for at least twenty-five writers before any model fits.

Represent a writer's available earlier text by the unit-normalized mean of all their encoded typed sequences. The population prototype is the unit-normalized mean of the available *other writers'* unit prototypes, giving writers equal weight. Each sequence has the completed encoder's frozen first-254-token visibility; this does not claim the full sequence was visible. A zero-norm or absent own/population prototype is unsupported, never silently a zero similarity. Record counts and a digest of every selected source-session set. The production sweep updates histories at session completion; fresh verification instead queries independently built per-writer prefix sums, compares exact identities/counts and requires feature agreement within absolute 1e-10, relative zero. A separate brute-force constructed oracle checks both selectors.

For every eligible menu retain the five unstandardized option features: cosine to own history, cosine to the population prototype, log-one-plus whitespace word count, zero-based menu position, and cosine to the preceding visible sentence. Dismissal has a zero feature vector and an explicit alternative indicator. Preserve past-five acceptance and log-one-plus seconds since last acceptance separately for later interaction with the option indicator. The existing earlier/later session split, overlap exclusion, canonical choice and distinct dismissal stay unchanged. Preserve the complete census and exclusion reasons. No feature standardization, coefficient, temperature, likelihood or scientific probability is fitted here.

**Smaller route.** A 140-session hash-order cost probe uses the complete past-history universe. Project full target preparation and fresh verification with a factor-three margin. Charge this work, constructed tests and earlier source/encoding costs to T4's existing cumulative 7,200-second ceiling; leave at least 900 CPU seconds for model validation and fitting. If projected whole work exceeds the remaining allowance, use the packet's separately frozen whole-writer sample route. The probe cannot establish scientific support.
