# S5: planning-run starts and released change gaps

The ratified primary is in [the Week 4 packet](PACKET.md). This implementation freeze precedes inspection of the empirical contrast.

**Case and check.** At least 30 planning-run starts in each of at least six project-scoped author identities. Constructed null, positive and reversed effects must recover, and dense generalized least squares must agree with the exact computational shortcut. Missing case support yields “design cannot test”; no sensitivity follow-up is created for that state.

**Smaller route.** The packet requires all ScholaWrite identities. A measured workload that cannot fit the unchanged cumulative allowance is cost-held; it does not drop authors or projects.

Use all 61,504 authenticated released changes. Group by project-scoped author, sort by source timestamp and original row index, and refuse timing across ambiguous timestamp edges. Runs use the high-level labels planning, implementation and revision. Fine-label runs are reported separately. A gap longer than 30 minutes marks a new session and is counted outside the primary, including when its label continues. Visible editor discontinuity is counted; the packet's released-change intervals can span publisher-filtered changes and are not claimed to measure raw keypress pauses.

Normalize each eligible gap by that author's median eligible gap, then take its logarithm. Include high-level run starts from authors meeting the planning floor and having implementation starts. The first fixed predictor is planning; implementation is its reference, with a revision indicator and log-transformed edit size and time since session start as covariates. Center fixed predictors within author to estimate the commissioned within-author contrast. Retain project and author random intercepts. Author IDs remain project-scoped; no cross-project identity is inferred.

For this centered design, the fixed-predictor matrix is orthogonal to both random-intercept indicator matrices. Its generalized least-squares coefficients therefore equal the within-author ordinary least-squares coefficients for every admissible variance choice. Check the equality against the existing certified crossed-intercept solver on the actual original fit and against independent dense covariance calculations on constructed data. Bootstrap 2,000 whole authors using their exact sufficient statistics, relabeling sampled copies conceptually as separate identities. This is an algebraic calculation of the same coefficient; failed or unidentified draws are not discarded. Use 200 within-author run-category permutations and seed 20261102. Report the interval and permutation reference together; a null retains untested population sensitivity until its required instrument follow-up.

Fit each author's descriptive three-component lognormal mixture with the existing PP1 quantile initialization, fixed Week 4 seed and convergence/collapse checks. These released-change gaps use the card's own median normalization, not a physical-keypress correction. Retain unsupported and failed mixture fits explicitly; the raw-gap primary does not depend on a mixture succeeding. Keep per-author details private and report aggregate category posteriors beside the primary. Report fine-label start/inside-run/long-break distributions separately.
