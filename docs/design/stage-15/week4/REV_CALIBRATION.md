The piece reader receives only piece text and the exact twelve-goal library.
It returns an empty list for none or up to two distinct codes, most likely first,
within 32 output tokens. The document reader receives only the numbered finished
text and returns three integer scores, zero to nine, per sentence: hesitated,
later revised non-locally, accepted from an offer. Its unchanged output budget
is ten tokens per sentence plus twenty. Thinking remains disabled. Both schemas
are explicit in the prompt and constrained in the request. The parser checks
the entire message, exact model, normal completion, keys, counts, order and ranges.

These format replies are discarded from scientific scoring. If the unchanged
prompt passes, a separately admitted main reads the complete populations anew,
including the calibration inputs, once; this fresh main was declared before
calibration and is not a selective retry. If format fails, preserve all outputs
and use at most the campaign's one recorded prompt correction on the frozen fresh
hundred; its second failure stops REV. No automatic correction or main dispatch
is implemented in this module. Accuracy is T2/T6's outcome, not a known-answer
gate or a reason to revise prompts. No generation assignment is sent to REV.
