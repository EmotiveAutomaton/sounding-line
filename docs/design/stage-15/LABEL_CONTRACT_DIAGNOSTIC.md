# Bounded label-contract diagnostic

This is the next small local F4 diagnostic under the curator's October 15
overnight continuation and healing authority. It does not extend the completed
fixed-reader queue, change its verdicts, fit human data or start a paid tranche.

**Question.** Do explicit label definitions improve the two persistent failures,
mixed grammatical person and absent themes, beyond target-field scoping alone?
**METHOD.** Compare the same scoped canonical prompt with that prompt plus a
fixed label-contract paragraph. Keep the schema, parser, model settings, target
and context identical within each pair. The person definition names pronoun-group
presence, not narrative viewpoint. The theme definition explains a set of present
tags, empty array for no listed theme, and unclear for unresolved evidence; it
does not give target-specific examples or answers. These are diagnostic prompts,
not changes to the canonical engine or previously frozen batteries.

Use 16 person targets (four per declared category) and 40 theme targets (four
per each of nine listed themes and four empty sets). Templates are enumerated
in the runner and read before launch. All are short constructed sentences,
not independent human annotation. Cross each target with a neutral context and
a context containing an incompatible person or theme. Cross both contexts with
both prompt arms, on Llama 3.2 3B and Qwen 3.5 9B. Run two byte-identical repeats
of each request, in separately shuffled complete passes, seed 151016. This is
896 calls across the fixed roster; do not select questions, classes or readers
after an interim result. Context contrasts test interference with the target,
not whether the context is false. Every target and prompt remains visible in
the retained plan. No motive attribution or natural-data inference is licensed.

**DESIGN CHECK.** LESSONS sections 2-5 and CONTROLS sections 1-3 re-read for this
design; READER_HEURISTICS sections 9-10 and correction history re-read.
NULL: unchanged, constant or malformed answers do not acquire a positive paired
benefit merely through scoring; a constant label fails at least one other label.
ALTERNATIVE: explicit definitions improve the intended classes while preserving
other categories and context stability. Negative, zero and positive contrasts
are all retained. Report each reader/question/class/context/arm denominator,
validity and correctness; paired improved/worsened/unchanged counts; context
answer flips; and exact-repeat disagreements. No p-values or promotion threshold.
Oracle fixtures must score correctly in every cell, with zero prompt benefit and
repeat disagreement; planted one-arm errors must give the expected signed
contrast. Duplicate/missing slots, unequal repeat requests and malformed inputs
refuse. Fully returned invalid responses count wrong; unknown transport, drift,
resource or residency failure stops the attempt and is not a scientific null.

Whole-roster fake-transport execution, retained wire replay, mutation refusal,
native-exit terminal validation and second-entry refusal precede launch. Freeze
this card, code, exact inputs, tests and canonical capsule. Output uses a new
`raw/label-contract-v1/` namespace, with no automatic retry or result salvage.
Only the whole completed diagnostic is scored and reported; full internal
write-through precedes ACK. Success would motivate a separate full admission
battery, never automatically enable a failed question or permit human fitting.

Use the same pinned models/runtime as the completed two-reader queue, one CPU
inference thread, zero GPU residency, temperature and seed zero, context 8192,
output cap 256; Qwen explicitly requests non-thinking. This is a reader-system
comparison, not an isolated model-size effect. Maximum 896 calls and 12 hours;
8 GiB free RAM and commit and 20 GiB disk floors. Require the exact project
service identity, exclusive lease and terminal/disappearance monitoring before
dispatch. Retain unknown-call evidence and lease. Unload only the owned model.
The six-hour health clock stays unchanged; no ETA polling or new delegation.

Literature check: [Ribeiro et al., CheckList](https://aclanthology.org/2020.acl-main.442.pdf),
READ introduction and sections 2.1-2.2 through the test-type definitions. Behavioral
tests and controlled perturbations are established evaluation methods; this is a
project-specific contract diagnosis, not a novel general method. The paper does
not validate these labels or license human-mechanism claims. The immediate
motivation is the completed F4 evidence and its definition-versus-capability
ambiguity, not a literature-derived change to the theory.
