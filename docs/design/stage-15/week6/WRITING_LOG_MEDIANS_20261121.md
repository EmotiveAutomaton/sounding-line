# Sentence beginnings and requests for writing help

CoAuthor records changes to a document and requests for suggestions. The registered observation is a writer. The first comparison uses the writer's median pause before starting a sentence divided by the median pause before starting another word in a sentence. The second compares her pauses before asking for a suggestion with the pauses she takes elsewhere at the same kind of position. Both use the existing source clock in seconds. Keep the two genres together for the registered writer-level result.

For WLG1 use the authenticated PP1 extract, positive intervals between single user insertions, and its sentence-start and ordinary word-start labels. For each supported request, compare its observed interval with the median control interval in its stratum. Divide the median observed interval by the median of these matched reference intervals for each writer. This gives comparison strata the frequencies with which that writer requested help.
