# Hawks diary build for member 0003

The released instrument distinguishes five sources of stress. Each item uses code 1 for an event that was not endorsed, 2 for an endorsed event rated as having no stress, and 3–5 for increasing stress. Keep 1 and 2 distinct. Use the five original fields `argument_stress`, `let_pass_stress`, `friend_relative_stress`, `health_stress` and `other_stress`. Exclude the pandemic-specific item from this commission. Use the release's within-person study day for both chronological splits. [Variable dictionary](https://openesmdata.org/datasets/0003_hawks/) · [Original version 1.0.0 release](https://zenodo.org/records/17347390)

Nervous, afraid, scared and distressed describe how the person felt immediately before responding. Worried asks how often the person worried **since the last survey**. Keep it in the five commissioned feelings and identify the recall interval in every associated result. Sadness asks how often nothing could cheer the person up in that interval. File that item separately. Fear, worry and severe sadness are neither interchangeable constructs nor simultaneous observations. The anxiety companion regresses nervous and worried separately on afraid and reports their different recall periods.

Hawks and colleagues used intensive repeated assessments to predict cognitive performance from changes in everyday conditions. The original study concerns performance, whereas the present registered question concerns the repeatability of emotional responses to different stressors. [Original study](https://doi.org/10.1016/j.bpsc.2022.12.002)
