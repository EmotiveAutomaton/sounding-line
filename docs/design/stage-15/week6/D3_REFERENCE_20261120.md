1. From the repaired source’s player identifier, actual attempt counter and repeat-history eligibility alone, select each player’s latest eligible repeat for testing. Reserve all 30 trials. Train using only that player’s earlier eligible repeats, with at least two such repeats. Attempt one can supply a reference. It supplies no choice observations to the training fit.
2. Write the support count and its hash before accessing choices, rewards or feelings. File the player and play flow, including too few repeats, ambiguous history, unavailable preceding attempts, and players with enough recorded plays but too few usable histories. Keep those reasons distinguishable. Use actual attempt numbers. The immediately preceding numbered play must be recorded to supply its ending score. The high-score reference retains MD3’s best observed prior completed-play score. State the number of gaps in available history.
3. In the original play-relative point units, compare the starting score (zero), the immediately preceding play’s end and the highest **earlier completed** play’s end. The last two can be negative. The selected play’s own end never enters its references. Before evaluating test choices, record all three pairs’ equal- and differing-reference counts. Report the paired log-likelihood difference on differing plays and on all plays beside it. A pair with fewer than 100 differing players reads *could not say*.
4. Use the original fixed-player-intercept choice model and its eight predictors. Hold the training and test rosters, forgetting factor and feature specification constant across the three fits. Fit all player intercepts from training choices alone. File the parameter count and any rank or convergence problem for each arm, including every post-support exclusion. A fair primary comparison requires comparable predictions for the same players.
5. Sum the 30 trial log likelihoods per held-out play. For each pair, take differences on the same players and draw whole players 2,000 times with the same registered allocation across arms. Report percentile 95% intervals. The primary requires the best earlier score to beat both alternatives on their differing-reference plays, with both lower endpoints above zero. Record the third pair descriptively. The player bootstrap quantifies held-out variation conditional on the fitted models. Replay the frozen computation independently.

**Design check.** Check chronology and actual-attempt gaps before any outcome access. Constructed cases cover exactly two earlier eligible repeats, a later ineligible play, identical reference values, 99 versus 100 differing players, strictly past reference updates, equal model dimensions, held-out intercept isolation and the paired log-likelihood calculation. The 10,000 CPU-second ceiling includes validation, execution and replay. No alternative split is selected after seeing outcomes.

**Limit.** The test speaks to late plays because it uses each player’s latest eligible repeat. The shape of risk-taking around a game score cannot establish what a person finds meaningful.
