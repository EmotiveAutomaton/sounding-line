## Optional reference ideas, not admission criteria

The archived `readme.txt` says rounds differ in prompt sets and production
strategy and rounds 7 onward balance the corpus. Inventory items are collected
at first participation, with copied/averaged writer responses documented.
It does not establish random assignment or exchangeability of prompt order.
No raw demographic or narrative values were read for this audit.

If separately commissioned, a restricted whole-writer wild reference could
probe each primary's zero-coefficient null while holding its declared nuisance
design fixed. One multiplier per real writer would preserve all within-writer
residual dependence, including IN14's shared survey boundaries, and would not
shuffle IN16's writer-constant N within its own writer. Its validity would need
independent writers plus an explicit conditional symmetry or large-cluster
justification and prospective constructed validation; it is not an exact
within-writer randomization test or proof of causal prompt assignment. It is
unimplemented and not part of these cards' present admission.

For a future writer-share reassignment, merely renaming whole writer labels is
also invariant. Any nontrivial report-to-writer reassignment would require a
justified conditional exchangeability scheme, preserve primary rows/covariates
and obey errata rule 5's paired contrast. It has not been designed or run here.

A 200-reference conditional-score bank would add about one tenth as many fits
as the existing 2,000 bootstrap draws, before replay, but that is a fit-count
comparison, not a measured CPU forecast. IN14's explicit global writer-dummy
reference can be substantially more expensive than production demeaning; the
ordinary in-slot cost probe must measure the full replay path. No separate
pilot or qualification campaign is created by this observation.
