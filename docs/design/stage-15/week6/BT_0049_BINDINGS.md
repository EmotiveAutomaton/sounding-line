# Member 0049 admission

Pronizius and colleagues examined mood and stress around helping in two COVID-period diary bursts. This release contains the first burst. The original study examined helping and perceived effort alongside affect. The commissioned analysis asks whether differences between people's response slopes repeat across periods. The same person reported helping, effort and subsequent mood. The effort question measures exertion. The survey did not ask respondents to evaluate the pleasantness of helping. [Original study](https://doi.org/10.1038/s41598-024-75261-z) · [Variable dictionary](https://openesmdata.org/datasets/0049_pronizius/)
