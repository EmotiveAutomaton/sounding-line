# B2 source projection and replay: constructed qualification

This additive component preserves the original eight literal string fields,
complete-pair validity rules, full Intervention union, session membership and
original common-cohort census. SQLite accumulation and an independently expressed
direct-pair replay must agree on every disposition and projected observation.

The handler accepts only a declared constructed envelope, bounded to 100,000 rows
and 32 MiB. These are engineering limits, not a scientific sample rule. It does
not open the original human archive or implement temporal halves, selected
triples, noise correction, reliability, multiplicity or human admission.

DESIGN CHECK: LESSONS sections 2–5 and the sampling-model correction. Under both
scientific directions, all valid pairs contribute Intervention. Missing required
fields refuse; malformed and duplicate responses retain their original excluded
dispositions. Nonfocal valid decisions and their sessions cannot disappear.
Changed inputs or tampered observations must fail independent reconstruction,
including when an output hash is recomputed. Fingerprints are linkage keys;
this component establishes neither person identity nor session chronology.

The native owner fixture passes all 189 constructed cases: exact membership,
pair dispositions, missing fields, original cohort boundaries, unchanged
original-producer parity, row/chunk invariance and hostile output/input mutations.
The installed adapter, fixture and literal bank are byte-identical to the
qualified private sources. Run the reusable fixture with
`python -m pytest -q tests/test_week6_tr2_b2_projection_v1.py` inside an owner-
reviewed counted test envelope while research is active.

The [complete qualification record](../../../../results/phase_2_4_stage_15/WEEK5/TR2_B2_PROJECTION_20261115.md)
retains the exact source hashes, native exit checks and inclusive charge.
Full checkpointed archive reconstruction and original-cohort reconciliation
remain unbuilt. Refusing/slowing sampling models and scientific controls still
need their own prospective review and qualification; this pass admits none of
the separate proposals. The original TR2/MD caps and actual Week 5 drain gate
remain binding for production.
