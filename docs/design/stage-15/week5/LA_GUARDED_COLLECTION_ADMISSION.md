# LA guarded checkpoint collection and admission successor

Prepared November 8, 2026. This extends the exact paired v5 implementation
through explicit collection and nonlaunching admission checks. Every prior
producer, collector, admission checker, design and prepared manifest remains
unchanged. Static construction and syntax/hash checks are the only work
performed here; all new qualification fixtures remain unexecuted.

## DESIGN CHECK

LESSONS 3–5 apply. A new scorer's source hash or a completed tiny fixture does
not establish a completed human reader bank. The positive numerical check
projects the actual completed constructed paired chain and compares the
original collection outputs byte for byte. The public production path must
still refuse that constructed chain as a human guarded producer. Altered
native identity, phase, guard threshold, load headroom, replay seal, model
binding, producer pin, missing qualification and nested/template completions
must refuse. The same rules apply regardless of the eventual scientific
effect. Original LA1/LA2 definitions, populations, numerical comparisons and
the one-percent unsupported allowance remain unchanged.

## Exact guarded producer acceptance

`week5_la_collect_v5` adds only the literal
`week5_la_scoring_guard_v1` identity. Existing v3/v4 producer acceptance uses
the unchanged old validator; old collectors still reject the new identity.
The final numerical projection/reduction runs the original v4 collection
function in a private namespace with the new producer validator. No frozen
module globals are changed.

For a new guarded producer the validator requires an actual Week 5 native
COMPLETE, a successful independent VERIFIED receipt, successful descendant
CPU accounting for both phases, stopped exact owner and child identities,
the authenticated native plan, all completed output bytes and all exact
source/model/numerical pins. The complete chain of preceding PAUSED attempts
must authenticate its manifests, identical inputs and complete configuration,
immutable native copy receipts, unchanged copied bytes and distinct owners.
Every predecessor's charges remain in the producer provenance.

It then checks the real primary ten-reader AT2 selection through the existing
full selection contract, including its complete corrected collection, and
requires the selected causal and original masked manifest bytes. Constructed
or partial selections cannot satisfy the production validator. The selected
model/tokenizer pair and common numerical specification must still agree
across every collected block through the unchanged original reducer.

Each completed act must retain its original value seal and complete independent
replay seal. The latter binds every immutable within-act file, including
causal and both masked arms, to the exact original source row and numerical
producer. The actual native verifier must declare full masked reforward and
immutable within-act replay. Original completed COST and all invocation
receipts remain preserved by the producer and native output manifest.

The monitor and load-admission evidence must belong to actual native execute
or verify child identities in that chain. Both current phases must have
returned guard receipts and both causal/masked load admissions. The original
26 GiB commit/20 GiB available-RAM load gates, seven-GiB cooperative requests
and six-GiB hard floors remain exact. Recorded guard CPU cannot exceed actual
descendant phase usage. A historical resource refusal is retained, but cannot
substitute for the two completed current guarded phases.

## Native identity compatibility correction

Static inspection found that the unexecuted v1/v2 LA request scaffolds expect
`creation_time` in OWNER records, while the actual Week 5 owner and phase
records contain exact Windows `created_ticks`. The new
`week5_la_native_evidence` adapter validates the actual native representation
and queries only those owned identities for exit. It runs the old admission
functions in a private namespace with that narrow correction. The v2 bounded
source chain still requires its original 40-row pauses, 69-row complete
population, all eleven source variants and exact replay; only its identity
comparison uses the actual FILETIME representation.

Guard receipts retain their original psutil Unix-epoch creation times. The
adapter matches PID, executable and converted creation time to the native
FILETIME record. A ten-microsecond representation allowance covers floating
epoch conversion from exact 100-nanosecond ticks; it is not a statistical or
model tolerance. A Unix-time-only owner record is refused. No existing receipt
is rewritten, and the defect was detected before these scaffolds executed.

## Nonlaunching admission version 3

`week5_la_admission_prepare_v3` preserves the earlier full-source, selected
reader, cost, context, source-qualification and scientific-scope checks. It
requires the actual paired original-output/refusal fixture and the exact
native execute-pause, verify-pause, complete chain before describing that
continuation as qualified. It distinguishes oracle-only from completed-chain
evidence and rejects nested fixtures or prospective request templates as
native proof. Separate native qualification of the collector/refusal checker
must follow that paired chain. The exact bounded-source qualification remains
independent of AT2 selection.

The new targets name the guarded scorer and explicit collector. A supplied
human score bank must contain every declared prepared block, each from that
exact guarded producer and exact source file. Inspection never launches,
copies a checkpoint, claims a lease or creates a runnable PLAN. All outputs
remain `nonlaunchable=true`, `ready=false`, `owner_reviewed=false` with unknown
forecasts and real paired resource measurements left unknown.

## Prepared fixture and remaining gates

`week5_la_collect_v5_fixture` consumes the real completed paired integration
fixture and all three actual counted continuation attempts. Its positive
constructed adapter authenticates those actual native receipts before using
the original numerical collection function. That adapter is local to the
fixture; the public producer validator separately refuses the constructed
native chain as a production scorer. Original output equality, complete
guard/replay provenance refusals, missing pins/unknown producers, template
rejection and the nonlaunchable admission result are all prepared controls.
An independent outer native verification repeats these metadata and projection
checks. No model is loaded and no human source is projected by this fixture.

The proposed qualification ceiling is 600 CPU seconds, 900 wall seconds,
3 GiB and two numerical threads. These are unmeasured ceilings, not forecasts.
Owner review, local design commitment and actual native qualification remain
pending. Human admission still needs the corrected full AT2 bank and admissible
reader, complete bounded LA source qualification, real guarded paired first
block evidence, simultaneous model and cold-load/transient-commit peaks,
atomic causal/eight-mask/checkpoint-authentication latency, measured full
independent replay and first-five-percent pilot cost, and current original
card/family room. Existing largest-reader verification holds remain. No sample
size, cost forecast or memory envelope is invented by this successor.
