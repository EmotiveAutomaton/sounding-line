# S4.k: a mouse click versus an arrow-key landing

Prospective Week 5 backlog implementation of Week 4 S4.k. CPU only; no paid,
GPU, Ollama, identity queries, contact with authors or new source acquisition.
The inherited card ceiling is 3,600 CPU seconds, shared across intake, source,
analysis and verification; the BK family continuation rule remains owner-run.

## Question and unit

Among moves landing at least one sentence behind the current leading edge,
does a mouse-click landing precede an edit within one sentence of that landing
more often than the last arrow-key move in a run, at the same sentence distance?
The primary direction is positive. This is an observed device association, not
a measured intention, attention state, causal device effect or physical hand pose.

Use the private, pinned WritingTask archive already acquired through the author
repository and released by the data owner under CC BY 4.0. Cite Tian, Crossley
and Van Waes (2025), DOI 10.17239/jowr-2025.17.01.02; acknowledge the KLiCKe

## Reconstruction and source gate

`week5_bk_s4k_navigation` reconstructs the textarea with JavaScript UTF-16
positions. Input/paste ends at the logged cursor; delete starts at it; replace
contains exactly one source separator and must match the removed characters.
Move spans must have equal lengths and valid bounds. Unrecognized operations
or escapes are retained as reconstruction failures. Escaped newline, tab,
backslash, quote and standard control characters are decoded without changing
ordinary Unicode. The independently exported final text converts CRCRLF or
CRLF to textarea LF and removes exactly one terminal export-record newline;
all writer whitespace remains significant. No content trimming or fuzzy match.
The initial five-source check supports this serialization rule; full source
execution validates it for each retained session before outcomes are accepted.

The source handler consumes an authenticated, complete intake, retains all
4,992 roster entries and all failed entries, and independently replays every
successful record in verification. Parse/reconstruction failures count jointly;
at most 1% passes collection. A contradictory source hash is an integrity error,
not a tolerated parse failure. Raw text and per-writer rows remain private.

Only nonstationary, text-unchanged Leftclick/arrow events enter the two arms.
Other cursor movements interrupt arrow runs. A run joins consecutive arrow
moves with unchanged text and gaps at most two seconds; only its final move
can land. A click followed by another moving click within two seconds is
pass-through. Geometry and sentence segmentation reuse the frozen S4 ruler.
Landing distance is 1, 2, 3–5 or more than 5 sentences from the current last
sentence. The editable neighborhood is the landing sentence plus one on each
side, tracked through intervening exact edits. Last observed key release must
leave the entire follow-up window; trailing landings are censored, never false.
Selections have only a logged endpoint; selection extent remains unobserved
and this qualification accompanies the result.

## Comparison, controls and complete bands

Primary: thirty-second window. Within each writer, compare click-minus-arrow
edit probabilities in shared distance bins, weighting each bin by the smaller
arm count. Average eligible writers equally. Eligibility requires ten landings
of each kind across shared bins; population floor is twenty writers. Compute
2,000 writer bootstrap resamples, seed 20261102, and 200 label permutations
within writer/session and distance bin, seed 20261103. These preserve arm counts,
matching and support. Identical probabilities use cross-multiplication to
preserve exact zero. Report permutation band and descriptive one-/two-sided
probabilities. A reference band excluding zero is biased and blocks support;
a nonzero constant writer effect has degenerate cluster uncertainty and also
blocks population support. The ordinary sign/zero bands remain exhaustive.

If the floor fails, fit a pooled distance-standardized difference across all
available writers, and report the available within-writer estimate and exact
support counts separately. No population interval is manufactured. With no
shared bin the pooled estimate is undefined, with its reason and counts, never
zero. Reliability/identification fake-writer controls do not apply: this card
neither predicts identity nor tests history or cross-session reliability.

Declared texture: sixty-second window, same reconstruction and reference with
200 cluster resamples, descriptive only. The S4(a) twenty/eighty-character jump
thresholds are geometry variants; S4.k's predictor is the directly logged device
and is not recoded by those thresholds. No new displacement subgroup is added.
This is an edit-probability contrast, not a typing-interval comparison; no hand-
switch delay is subtracted or interpreted as mental preparation. Unsupported
data do not trigger a sensitivity follow-up as if they were a null.

The analysis supports cooperative interruption every fifty completed draws;
this short unit restarts deterministic inference in a new attempt. Source
execution yields at session boundaries, while its verification is a complete
restart unit. Owner review and committed design/native proof precede any human
navigation execution. No scientific result is contained in this note.
