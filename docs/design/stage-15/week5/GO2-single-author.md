# GO2 single-author-history texture

Packet section 0.6 requests an author-cluster texture dropping multi-author
proposals. Current headers cannot establish authorship at an earlier goal
revision, and the frozen GO2 anchors did not retain historical multiplicity.
This isolated successor records that support directly from the same pinned
local histories. No live h2 job or existing source file is edited.

`week5_go2_authorship_source` is the retained h2 source with only an additional
per-document classification and two aggregate counts. A document is excluded
from this texture if **any eligible observed licensed revision** has multiple
authors. Each anchor carries the resulting boolean. Counts include documents
with eligible authorship and those with an observed multi-author revision.
This conservative document-level restriction avoids pretending that a final
single-author header establishes a single-author history. Missing, unlicensed,
binary or undecodable revisions remain outside observed scope under the same
h2 rules; this texture makes no claim about their unseen authorship.

The source retains exact copy/rename/deletion and unreadable-version barriers,
strict decoding, source pins, first-listed author keys and all original anchor
values. `week5_go2_authorship_bounded` keeps per-document seals, bounded work
quanta and complete independent replay. Original anchors remain immutable.
Removing only the new field from the constructed successor anchors must
reproduce every original h2 anchor exactly.

`week5_go2_single_author` filters these authenticated source-supported anchors
before applying the unchanged three-before/three-after support test and its
one-before/one-after fallback. Encoder, added-text definition, old/new goal
contrast, reverse-direction comparator, author grouping and interval estimator
are unchanged. Missing or non-boolean historical flags refuse. Report source,
excluded and retained anchor counts. At 200 draws this is descriptive texture
and cannot upgrade the primary. The original below-floor fallback remains.

## DESIGN CHECK

- **Case and check:** a current single-author document can have a multi-author
  goal-change history. Native constructed Git histories contain both cases;
  the source must preserve every h2 anchor while distinguishing them. Its
  document pause, seals, immutable copied continuation and full fresh replay
  must verify. Complete signed and null numerical handlers use constructed
  encoder vectors with the same fixed filter and 200 author-cluster draws.
- **Smaller route:** first count a source-only 5% document pilot in a counted
  slot; then use whole-author sampling if required by the measured total.
  All preparation/replay and scoring stay inside the ordinary 3,600 CPU-second
  texture ceiling and 600,000-second GO family ceiling. This wrapper's
  document/text/CPU quantum keys are semantic under the present adapter and
  therefore stay fixed on every continuation. If finer bounds are needed,
  obtain a separately reviewed execution successor before admission.

The fixture qualifies historical metadata and exact estimator reuse, not human
authorship truth or encoder accuracy. Prior actual encoder validation remains
required. Source re-projection has a real cost and is not represented as a
free field recoverable from completed anchor JSON. No corpus pass is launched
by the builder.
