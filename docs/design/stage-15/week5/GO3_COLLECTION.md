# GO3 complete five-site collection and source-support gate

DESIGN CHECK: LESSONS 2–5 and the frozen GO3 source/analysis contracts. A
completed filename is not proof of a complete source. All five independently
replayed sources, site/archive/licence/salt bindings, exact schema, row counts
and exclusions must authenticate before source collection. No classifier,
IteraTeR model, prediction, accuracy or personal-habit effect is fitted here.

The collector's only input is a frozen roster mapping Writers, Philosophy,
Academia, Worldbuilding and English to one complete source-attempt root each,
with the exact COMPLETE checksum. Duplicate roots, missing sites, changed
completions, ambiguous PAUSED/FAILED terminals or missing explicit complete
source replay refuse. All files named by each terminal are rehashed. Producer
module, archive pins, two XML members, licence notice and shared campaign-salt
hash must agree with the current frozen source contract. Source and failed
attempts are never edited. The packet's fewer-arrived-sites fallback is not
silently selected while all five retrieved sources are still finishing.

The full parquet projection is byte-authenticated, while only the eight
metadata columns needed for support are scanned: salted editor/post keys,
timestamp, site, edit type, mapped reason, self-edit and owner-known status.
No before/after text or original reason comment enters this scan. Schema and
sorted post/time order are checked, every retained row is counted, and the
producer's attempted edits reconcile with retained rows plus anonymous,
missing-predecessor and unchanged-text exclusions. Unknown categories or raw
identifiers refuse. Salted keys and complete source paths stay private.

A transactional private SQLite table accumulates exact per-editor/category
counts and first edit times for each edited post. It saves its complete row
cursor at every 4,096-row metadata batch; the last source batch may be shorter.
The first `ceil(0.05 × total declared metadata batches)` completed batches
form the counted pilot, once in execution and once in independent replay.
Authentication is separately charged and revalidates all bytes on every
attempt; this pilot does not extrapolate hashing, final support assembly or
verification cost. Resource/wall interruptions preserve committed metadata;
the stopped database is closed and fully hashed before an authenticated copy.
The existing runtime v7 handles its exact DELETE-mode rollback journal.

The support gate reconstructs the original five user-disjoint fold assignments
from sorted salted editors and seed 20261107. For the full primary, self-edit
cell and each site it reports user counts, five category counts and all train/
test fold counts. At least twenty users and all five categories in each
training fold establish design support only. Otherwise the existing pooled
descriptive route remains; if fewer than two categories exist, retain counts
instead of inventing an estimable model. The omitted-IteraTeR cell shares the
full primary's source support but still needs its actual feature consumer.

For the habit companion, whole posts are ordered by first observed edit time
with retained source-order ties and alternate between halves, exactly as in
the frozen consumer. Three seeded roles and fixed thirty-person galleries
are reconstructed. Report whether every actual probe/gallery half has
independent same-site, same-post donors. This is a structural support check;
it computes no reason-distribution distance or accuracy. Support under all
1,000 conditional permutations remains a downstream scientific obligation.

Completion emits a private COLLECTION binding to all five projections and an
aggregate SUPPORT receipt. `scientific_admission` stays false. Full independent
verification reauthenticates every source, rebuilds every metadata table from
row zero, compares all rows in canonical order and matches every summary.
Only that completed collector can supply the next feature-preparation input.
The original source and analysis modules remain unchanged.

Native qualification uses two explicit artificial five-site producer-envelope
fixtures: all category/fold/gallery support present, and a missing primary
category that must retain the descriptive route. Artificial COMPLETE records
are fixture inputs only, not actual native source claims. Tests additionally
exercise changed bytes, swapped sites, missing sites, ambiguous terminals,
changed checkpoints, absent users and below-floor cases. Actual counted
pause/copy/continuation and complete independent replay remain unexecuted
until owner review. The fixture does not run a statistical model.

Initial unmeasured planning envelope: at most 3 GiB RAM and a 900-second wall
quantum, within the existing GO3 250,000 and GO 600,000 CPU-second ceilings.
Qualification, source authentication, pilot, copy, failures and full replay
are charged. No new scientific card or separate allowance is created. Owner
admission must use actual remaining family/card resources and the first
measured metadata pilot before a complete continuation. This build is not
yet qualified and authorizes no launch.
