# AT/LA source and scorer checkpoint addendum

The original AT covariate wrapper is not admitted: it called the historical
raw-screen routine before its recorded literal-empty-reopen recovery. The
separate `week5_at_covariates_v2` calls the retained exact UTF-16 successor,
which includes that existing recovery. It still refuses malformed suggestions
and preserves the original predictor clock. Every admitted literal empty
reopen is recorded by event ordinal in the private audit. Original source,
scoring and covariate wrappers remain unchanged.

The native full-handler fixture uses real-format raw JSONL events, the P6 word
schema, source checksums and the ordinary output index. It verifies prompt,
prior API text and prior displayed suggestions, excludes the current insertion,
future displays and the option's unshown original text, and replays the empty
reopen audit. Execute and a separate fresh verifier both pass. This is a source
mapping check, not a human result or authority to drop unsupported events.

`week5_la_pipeline_v2` preserves all old preparation, matching and scoring.
Its only scoring change checks `YIELD_REQUEST.json` before loading either model
and after each complete paired act, during execution and verification. A native
fixture uses actual tiny causal and masked transformers, interrupts after the
first act, resumes the second and independently recomputes both paired scores.
Original LA pipeline pins remain unchanged. Use the successor for new reader
scoring plans; source preparation and LA2 can continue through the original
admitted preparation path.
