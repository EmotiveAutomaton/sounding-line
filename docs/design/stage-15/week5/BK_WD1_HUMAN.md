# WD1 corrected conditional-reference consumer

This implements the exact-profile reuse already permitted by the Week 4
support-correction design. It leaves the original invalid result and both
failed fast-solver attempts intact. No human run is released until the complete
thirty-world corrected calibration and its fresh verification pass.

## DESIGN CHECK

**Case and check.** Authenticate every original source pin, output and full
independent-replay record, the complete conditional support bank and the passing
calibration campaign. Reconstruct the full population features and exact
outcome-blind accepted assignment stream. A profile may be reused only when its
original proposal, assignment, source, output hash and supported roster agree
exactly. Only accepted assignments absent from the original thousand receive
new fits. These use the unchanged validated Newton/probit solver and its original
certificates, and each is refitted independently. Complete collection requires
all 1,000 references and the unchanged 2,000 paired writer bootstrap draws.
Native known-answer fixtures exercise the actual new-fit handler and exact
reuse/full reduction, including refusal of missing or duplicated assignments.

**Smaller route.** Keep all supported writers, all references and all bootstrap
draws. Cost the missing fits, source reconstruction, complete summary and fresh
verification inside the same Week 5 WD1 allowance and BK family ceiling. Smaller
execution blocks do not change scientific support. An execution block contains
at most fifty missing assignments, with sealed checkpoints and resource-yield
checks at each complete fit. No unverified profile or smaller control bank is
substituted to fit a budget.

The original invalid reference bank still exists as historical evidence.
Corrected output is a new conditional, descriptive contrast, with the unchanged
primary summary, criterion reliability and session-thirds companions. Conditional
assignment validity does not establish human exchangeability, independent
quality, competence, learning, payoffs or causal mechanisms. Retain G223/G234's
independent-optimum qualification. Private profiles and participant identities
remain in ignored storage; only aggregate claim records can be committed.

API: `week5_bk_wd1_human` exposes source (original completion, corrected support
root, passing calibration root), new-assignment block, and full reduction.
The source receipt reports the number of authenticated reused profiles and
missing refits. Its generation does not publish a corrected score. No owner
admission or calibration gate can be inferred merely from this implementation.
