## DESIGN CHECK

EX4 reconstructs a benchmark, not a theory-channel response. The complete
export, unsupported timing, source/replay parse exclusions and planned pauses
must all remain operations without inferred activation. `activation: []` is
therefore required beside `record_kind: run`, `theory_tags: []` and the existing
`by_construction: false`. No word, pause or source exclusion is evidence that a
particular emotional channel fired.

`week5_ex4_v3` is an isolated copy of v2 with only producer-version identity and
operation metadata changes. The complete SUMMARY and RESULT, both pause return
branches, complete/yielded verifier returns and materializer return carry the
four fields. Source integrity exceptions still propagate to the counted
runtime; they do not become success, a parse exclusion or a fabricated output.
Runtime-level FAILED filing is still the owner's operation record. Session
dispositions and words are source/annotation rows, not new scientific result
rows; no fields are inserted into their original payloads.

Every session document, final-text byte, word span/order, provenance/timing
value, stop threshold, parse disposition, INDEX and README stays identical to
v2. Only aggregate operation metadata, its recorded hash and the required new
producer identity change. Original corpus attribution and local-only boundaries
are unchanged. No original source definition, parser, roster, estimator or
export destination is replaced. A v2 checkpoint cannot cross into v3 because
the producer identity and source binding differ.

## Focused qualification

Seven proposed constructed checks reuse the existing fixture and its literal
session generator. They cover exact v2 session/INDEX/README parity, complete
aggregate and verifier metadata, both pause routes, source-parse failure,
replay failure, a final word with unsupported bulk timing, integrity-exception
propagation and old-producer checkpoint refusal. They do not rerun the broader
22-check suite or add a scientific model. Expected unchanged fields are compared
to the frozen v2 computation; explicit metadata values and unsupported timing
are asserted separately. Earlier independent word/offset/timing checks remain
the extractor qualification rather than being replaced by this parity check.

The old fixture deliberately substitutes corpus authentication and native
pause/copy receipts. That limit persists. These focused checks do not prove
real corpus authority, native exits/leases or actual archive replay. They must
run only after the owner's serial token, under the retained 180-wall/150-native-
CPU-second bound and two numerical threads, with all old/new pins checked before
and after. No recipient copy or real source access is part of qualification.
