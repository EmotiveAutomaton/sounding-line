# GO1 complete readers and declared grid

DESIGN CHECK: LESSONS 2–5 and CONTROLS 6–7. The case is a licensed document with an author-stated goal and a supported fixed candidate roster. All three readers use the same roster and their intersection of full-document context support; a missing reader never becomes a complete primary. The smaller route samples whole author clusters prospectively after an in-slot first-five-percent cost pilot. Context exclusions and sampled share are reported, not interpreted as incorrect predictions.

`week5_go1_pipeline.py` retains the original 49-distractor retrieval and author bootstrap. The sole primary is conditional language-model retrieval minus TF-IDF. Accuracy above chance and encoder-minus-TF-IDF are secondary. Every score is for a fixed query/candidate allocation; exact ties retain the allocation's seeded random order. Below twenty authors is descriptive. The 99-distractor texture requires 100 eligible documents in the same stratum and never fills missing candidates from elsewhere. The nine-distractor texture uses the original fallback rule. PEPs and EIPs/ERCs also run separately, and Specification replaces the rest in its registered texture.

The first-version and final-version texture uses the same matched document set. The first version is explicitly the earliest eligible licensed Motivation-bearing version from GO2's source history, with exclusions counted. It does not assert access to an earlier unlicensed draft. Each version gets its own fixed roster under the same allocation rules; reported version differences remain descriptive.

The conditional-likelihood reader requires an authenticated full AT2 result with `selection_admissible=true`, the selected model's exact manifest, and its full-context capacity. It computes SUM log likelihood gain, not a token mean, checking the scalar against the saved individual token losses. Each likelihood starts with a fresh model cache so resuming at a later query or repeating an identical candidate cannot change its score through earlier cache state. No AT2 screening winner or invented selection can satisfy this dependency. Queries whose complete rest plus any candidate does not fit are counted as context-unsupported for all readers' common comparison.

The supported branch uses Rationale as the hidden target. It reconstructs section ranges from the pinned raw document at the selected revision, removing the whole Rationale subtree and copyright before scoring; substring replacement is not used. Motivation can then remain as legitimate evidence for the stated reasons. The alternative branch draws other types/categories first and reports allocation fallback. These branches are not both automatic: the complete parent result chooses the registered route.

Encoder work seals individual text vectors; language-model work seals complete candidate rows. Seals bind model assets, code, source text/allocation and context. Operational limits `max_new_texts`, `max_new_queries` and `max_cpu_seconds` yield progress without a result; complete checkpoint validation precedes reuse. Independent verification reconstructs the full result and compares every score. The 150,000 CPU-second card and 600,000 family ceilings include all preparation, scoring, fitting and verification. Raw text, hashed author keys and score banks remain private.

Admission of the language-model arm remains dependency-waiting until AT2's complete primary selection exists. Constructed fixtures can validate algebra, rosters, actual encoder calls and selected-model guards, but cannot stand in for that scientific dependency.
