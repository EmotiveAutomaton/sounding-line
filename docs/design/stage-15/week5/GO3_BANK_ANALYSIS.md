# GO3 complete-bank scientific adapter

DESIGN CHECK: LESSONS 2-5 and CONTROLS 6-7. Preserve the original hypothesis,
fourteen diff features, external intent probabilities, training-fold standardization,
five editor-disjoint folds, class-prior expected confusion, 0.05 macro-F1 gain bar
and uncertainty counts. Complete-bank authentication and original-model numerical
parity are gates before admission. Strongly informative constructed features must
recover the declared gain; uninformative features cannot pass. Identical contextual
reason distributions must give exactly zero real-minus-context habit difference
and fail the habit gate. Sparse cells retain the original pooled descriptive route.

This is an immutable adapter to `GO3-analysis.md` and `GO3_COLLECTED_FEATURES.md`.
It accepts one final `feature_run`, verifies every terminal output and explicit
full-training/full-feature replay certificate, and checks every sealed block's
source order, row count and logical contents. It refuses partial, extra, reordered,
changed or mis-scoped banks. The feature bank keeps all five original sites; the
analysis reads all rows before applying the original classifier's subset. The
habit companion receives every source row, including title/tag and non-primary
reason categories. Original whole-post halves, timestamp ties, three roles,
thirty-person fixed galleries, donors and seeded allocations are unchanged.

Every declared grid cell uses the original fixed configuration: the primary has
2,000 whole-user resamples and the seven textures have 200. There is no custom
draw-count option. Each complete held-out fold is saved with its model arrays,
test indices, predictions and training-only class priors. Bootstrap checkpoints
retain every ordered draw and replay the original generator sequence on resume.
The first ceiling of five percent of each classifier's draws triggers a single
counted pilot boundary after the complete upfront folds. That upfront fit cost
is charged; it is not represented as a five-percent model-training sample.

The primary's habit companion retains every one of the 1,000 original conditional
reassignments and all 2,000 paired whole-user resamples. Its first fifty reference
draws form a separate saved boundary inside the same card. The model is not
rerouted by a partial result. If a fixed gallery loses support, retain its exact
failing draw and all earlier reference values, mark the companion unsupported,
and do not discard or redraw it. This matches the original stopping behavior;
the incomplete reference is never called a passed control.

Execution and fresh verification independently cross their own pilot boundaries.
Every saved fold/model/prediction, null value and resample is compared after full
replay, in addition to the complete aggregate result. The only mutable operational
parameter is `max_wall_seconds`; cell, full-source scope, memory envelope and all
scientific definitions remain bound. A runtime continuation must copy the complete
authenticated predecessor output into a new attempt; originals stay immutable.

The original full-frame implementation may be expensive on large complete dumps.
Before any fit the adapter records parquet uncompressed bytes and applies a
four-times-byte planning estimate against a frozen `max_frame_GiB` (default 3).
This is a conservative gate, not measured RAM. If it fails, the card yields with
no scientific fit; the owner must freeze an adequately resourced semantic plan
or the packet's separately prepared whole-editor sample. The adapter never
silently truncates source rows. Native cost and the completed collection census
must inform admission. The longest model fold and reference draw are atomic;
their measured duration must fit the selected attempt envelope.

All qualifications, source/model work, pilots, fits, failures, textures and replay
remain inside the existing GO3 250,000 CPU-second card and GO 600,000 family
ceilings and actual remaining balance. No new budget or human launch follows
from this code. Under a sample route all rows of selected editors must remain,
scope must be labelled, and support/fallback checks rerun before inference.

Qualification is split visibly: fixed positive and uninformative worlds exercise
all eight cells with their complete counts and exact original-analysis comparison;
a separate actual complete counted feature-fixture input exercises the full bank
authentication path and numerical replay. Both are required. Neither is a human
finding, and neither permits a feature-only or source-only result to enter the
claim ledger as a scientific effect. All new tests and native fixtures are built
but unexecuted pending owner review.
