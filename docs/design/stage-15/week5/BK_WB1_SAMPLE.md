## Scientific and source invariants

The projection retains original symbol rows, clocks, raw and timeline hashes,
session order, original descriptor ordinals, bin edges and writer partitions.
Candidate pieces are recomputed using only the selected discovery writers,
with the original occurrence/writer thresholds. Candidate occurrences and the
unchanged first-tenth cost selection are then recomputed for that sample.
No participant query, occurrence trimming, successful-draw filtering, candidate
pruning or full-population discovery leakage is introduced.

The explicit successor consumers are:

- `week5_bk_wb1_coverage_scoped`;
- `week5_bk_wb1_encode_scoped`;
- `week5_bk_wb1_reduce_scoped`;
- `week5_bk_wb1_coverage_pilot_scoped`;
- `week5_bk_wb1_pilot_forecast_scoped`.

They preserve the original numerical bodies and switch only the authenticated
source/consumer imports and scope sidecar. Module identities are explicit;
original and scoped completions are not interchangeable. The original exact
sixteen-text checkpoints, four complete 200-reference banks, requested 2,000
writer draws, whole/thirds controls, 200 effect references, class discovery,
support rules and pooled descriptive fallbacks remain. A sample result keeps
its original scientific result fields plus a separate `SAMPLE_SCOPE.json`;
scope cannot silently disappear into an apparent full-population result.
The sidecar excludes writer identities. Raw rows and the private selected-writer
roster remain in ignored storage. Any inference is explicitly sample-scoped.

constructed source. Its fixed three-writer case preserves all six sessions,
and its all-four-writer projection equals the original population. This is a
software test size, not a proposed human sample. It checks order/outcome
invariance and rejects altered seeds, missing/extra writers, wrong trigger,

The actual sample handlers run complete cost work, all four reference banks,
the exact five-percent global reference prefix, full raw effect encoding and
the original effect/class reducers. Their outputs are compared to the actual
original cost, coverage and effects functions fed the same explicitly
constructed projection. Oracle functions receive that projection at their
source-load boundary through private function globals; no original module or
completed source is changed. Original below-floor dispositions stay intact.
Independent verification copies encoding outputs without prior verification
proofs and recomputes them, while preserving the originals.
