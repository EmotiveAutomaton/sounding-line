# LA masked-resolution checkpoints within an act

Prepared November 8, 2026. The source census found a genuine missing execution
component: the original masked reader completes both full old-token arms before
the paired producer can yield. This isolated primitive adds checkpoints between
its existing eight-position tensor batches. It does not replace a scientific
measure, load a model, supply a selected reader or qualify a human bank.

## DESIGN CHECK

The case is a long act whose masked work outlasts a cooperative resource
request. The check invokes the frozen original masked helper on each exact
original eight-position slice and compares complete outputs with the original
unsplit scorer, including identical old tokens, cropping and final reduction.
Interrupted or changed source/model/checkpoint data refuse. A uniform model
must still return exactly zero. The proof is prepared, not executed.

The smaller route remains the existing measured whole-meeting route. No
masked token, arm, source act, numerical tolerance or context is dropped to
save cost. A native tensor forward remains atomic: actual model timing and
peak memory still require measured counted admission. Splitting checkpoint
boundaries is not a claim that a forward fits the resource grace period.

## Exact primitive

`week5_la_mask_checkpoints.ResolutionScorer` subclasses the original scorer.
It uses the original `score` method unchanged, including tokenization, the
512-token paired crop, positions and reduction. Its `_pll` calls the original
helper on one original eight-position batch at a time. Tensor construction,
masked positions, model call, float32 conversion and cross-entropy are therefore
the original operations, with the same ordering and batch shape.

Each act receives its own private directory and explicit source-row and masked
manifest hashes. Both are bound with the actual text digest, core hashes and
fixed numerical configuration. Each before/after tensor batch has an immutable
value file and seal. Execute and independent verification use distinct prefixes;
verification recalculates every batch and keeps the original 1e-5 comparison.
No completed execute prefix is treated as independently verified. Reentry
retains complete output and every invocation's cost receipt.

The primitive raises a dedicated `MaskCheckpointYield` only at safe boundaries
between original forwards. Its caller must translate that signal into the
counted runtime's paused result. It neither catches a numerical failure as an
unsupported act nor changes the original length/support failures. Default
limits are 32 new masked batches or 600 wall seconds per invocation. They are
operational quanta, not measured forecasts.

## Remaining integration and admission

The existing paired v4 producer, collector and admission scaffolds stay
immutable and do not yet consume this primitive. A separately reviewed paired
producer must bind a unique source act, preserve causal scoring and selected
AT2 identity, catch its yield explicitly, and keep partial verification evidence.
Its collector must explicitly accept that exact producer and its full numerical
provenance. A native paired-load guard and measurements for both simultaneous
models remain required. No arbitrary memory envelope is inferred from weights
or the isolated AT measurements.

The prepared fixture uses actual tiny constructed masked transformers, original
versus checkpointed full outputs, exact uniform null, paired cropping, partial
copy/reentry, changed-source/model/seal refusals and a pre-forward resource
request. An independent outer native verifier reruns the original and new
paths. Local copied checkpoints do not claim stopped-native continuation proof.
Suggested owner-review cap is 600 CPU seconds, 900 wall seconds, 3 GiB and two
threads; all are unmeasured qualification caps. No tests, model execution,
source projection, native start, commit or ACK occurred while preparing this
component.
