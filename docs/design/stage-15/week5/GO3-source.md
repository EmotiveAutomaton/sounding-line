# GO3 stated-reason source and numerical contract

DESIGN CHECK: LESSONS 2–5 and CONTROLS 6–7. Comments supply a reason label and are then dropped; no comment word enters a predictor. Native archive projection must reconstruct ordered before/after bodies, self-edit status and salted joins. Missing preceding text or editor identity is an explicit exclusion. No public profile is loaded.

Five April 2024 Stack Exchange dump archives—Writing (legacy archive name `writers`), Philosophy, Academia, Worldbuilding and English—are pinned by locally verified SHA-256 after published size/MD5 checks. The supplied `license.txt` notice is CC BY-SA 3.0, requiring attribution on republication. All source text and identifiers stay private; only aggregate results are intended for publication. This notice is recorded as the dump's notice, not silently replaced by a different modern website licence. Retrieval failures for Worldbuilding and the notice were retained; the archive metadata's alternate server subsequently delivered the same pinned files.

The parser extracts only Posts and PostHistory. Users and profile material are not opened. Source user/post identifiers are salted before any SQLite join table or derived row is written. Posts provide only author linkage. History is ordered by post, creation time and source history order, preserving separate title/body/tag tracks. Initial states have types 1–3; edits have types 4–6 and 24. Anonymous editors, missing prior text and unchanged text are counted exclusions. The task retains body edits of types 5 and 24 for the primary. Every row is streamed into parquet, and independent verification compares all rows in bounded batches.

The frozen keyword dictionary in `week5_go_revisions.py` maps spelling/typo, grammar, formatting, clarity, added content, removed content, links and tags. No match is `other`; multiple categories are `multiple`, reported separately rather than assigned an outcome-dependent priority. Primary classification is restricted to five text-body categories: spelling/typo, grammar, clarity, added content and removed content. Formatting, links and tags are scale-only because they are partly definitional from the proposed predictors.

Predictors are diff-only character and token counts, exact token Levenshtein distance after unchanged prefix/suffix removal, punctuation/link/code/newline/spacing/case changes, and later the admitted IteraTeR-trained classifier probabilities. No source comment, user identity, self-edit flag, timestamp or site is a model feature. Five validation folds keep users disjoint. The specified prior-only comparison is a stochastic predictor from training-fold class frequencies: expected confusion is used directly, avoiding Monte Carlo noise and the inappropriate majority-class macro-F1 baseline. User-cluster intervals condition on the fixed out-of-fold predictions. A missing primary class in any training fold or fewer than twenty user clusters is unsupported.

Current admission covers source construction and the component fixtures only. The complete GO3 analysis still requires the IteraTeR feature consumer, full out-of-fold signed/null fixtures, the three-role user-habit companion and the declared site/self-edit/excluded-classifier textures. It must not emit a complete scientific result before those paths are built and reviewed.
