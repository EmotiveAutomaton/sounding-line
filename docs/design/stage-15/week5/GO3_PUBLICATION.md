During one native child's call, the adapter replaces only the shared GO3 core's
JSON writer with the separately retained UUID writer. Its JSON values, indentation,
finite-number refusal and ten bounded Windows replace retries match the prior
writer; newline bytes are explicitly LF. The temporary suffix becomes UUID32 so
the existing exact supervisor rule applies. The original callable is restored on
success, pause or exception. Array/parquet writers, model objects, source scanning,
thresholds, random generators and statistical functions are not replaced.

The production bank accepts only the new production feature-module identity.
The actual-bank fixture accepts only the new feature-fixture identity. Its one
existing producer-name constant is scoped to the new exact fixture identity and
restored after the call. No broad producer allowlist is introduced. Full numerical
functions and original parity oracles still come from their unchanged files.

Each successor creates a sealed `PUBLICATION_IDENTITY.json` naming its module,
wrapper/delegate/helper source hashes, inputs and semantic configuration. Only the
existing operational wall quantum is omitted from semantic equality. Verification
creates and checks the same identity in its independent replay directory. All
original inner feature, model, fold and reference bindings remain intact; added
identity fields live in sidecars and verification evidence, not scientific result
rows. A changed wrapper, input, cell or memory scope refuses. Earlier unbound
outputs cannot migrate into this successor. No completed source collection is
changed or recomputed merely for this adapter.

The non-statistical counted I/O fixture uses the actual UUID writer and unchanged
output-size function. It first proves a present temporary file counts, then makes
the real atomic replacement occur at the temporary's lstat boundary. It separately
requires ordinary-file disappearance and permission errors to fail. On Windows it
opens a real non-delete-sharing read handle, observes replacement denial and lets
the unchanged bounded retry recover after handle release. Complete case files and
their hash-sealed state persist; unsealed or altered cases refuse. The first case
pauses both execution and fresh verification, allowing a three-attempt immutable
native pause/copy/replay chain. This proof exercises no model or human source.

The initial I/O proposal is one counted lane, two numerical threads at most,
60 CPU seconds, 600 wall seconds and 1 GiB per separately reviewed attempt. This
is an unmeasured safety envelope, not measured cost or new allocation. Native
owner, source pins, complete output hashes, immutable predecessor and lease exit
must be inspected by the owner after each attempt; no loop starts the next one.

must complete feature qualification through the new wrapper, preserving the real

The new admission preparer retains all previous source, cost, exact native proof,
