# LA human-bank admission scaffolding

Prepared November 8, 2026; no new execution or admission. This engineering
supplement preserves [LA](LA.md), [its implementation](LA_IMPLEMENTATION.md)
and the immutable [paired completion repair](LA_IDEMPOTENT_COMPLETION.md).
The latter's original preparation status is historical: the actual counted
`LA-idempotent-completion-native` receipt completed both phases. It is a tiny
constructed lifecycle qualification, not a human-bank, cost or memory result.

## DESIGN CHECK

The case is admitting the exact real source and selected reader without
mistaking software evidence for a measured machine envelope. The check is
authentication of actual native completion, source and model hashes, original
numerical bindings, independent verification, and every retained cost. Missing
selection, ambiguous terminals, changed pins, or incomplete source rosters
remain explicit prerequisites. No scientific value selects an admission path.

The smaller route remains the already declared measured whole-meeting sample,
stratified by corpus using Hamilton allocation and seed 20261102. No count is
chosen here. The first five percent of work is an in-slot timing prefix, not a
scientific sample. Neither a count of meetings nor the tiny-model fixture is
assumed to be five percent of masked-token work. The unchanged below-twenty
meeting descriptive fallback is retained.

## One-stage requests and actual gaps

`week5_la_admission_prepare` only authenticates metadata and writes a new
private review request. It cannot write a runtime `PLAN.json`, launch, sample,
score, call a model, claim a lease, ACK, change a budget or publish. Every
output remains nonlaunchable and not ready, including when dependency receipts
exist. It has not been tested or executed; only its syntax has been inspected.
Its prepared request templates are deliberately incomplete.

1. **Source preparation.** The existing exact primary config is both corpora,
   five previous completed acts, vocal marks only, last-second/two-second
   outcome window, all speakers. Eight-act blocks and full source replay are
   preserved. The current preparation has no cooperative yield boundary. An
   exact bounded successor and constructed equivalence/refusal proof, or an
   actually measured complete-stage bound, precedes large preparation admission.
   The complete preparation supplies the eligible-act work denominator.
2. **Selected reader.** Authenticate the complete native AT2 selection and its
   complete ten-reader corrected collection, final context length 1,024,
   primary 2,000 draws, selected revision and manifest digest. Keep its actual
   source scope explicit for owner review. A timing pilot or constructed reader
   receipt cannot release LA1. The selected-reader check performs no analysis.
3. **Paired first block.** Freeze the exact first eight-act source block and
   both selected manifests. A real cost qualification is counted under LA1,
   within the LA family, with explicit owner-reviewed caps and actual headroom.
   Caps are not forecasts. A qualified paired-load/resource guard and measured
   largest-act yield latency are still missing. The current scorer checks yield
   before loading and after a whole act; the tiny fixture does not establish
   that an expensive act can finish inside the resource grace period. Do not
   reuse AT's isolated-reader memory envelope as proof for simultaneous readers.
4. **First five percent.** Freeze an ordered prefix covering at least five
   percent of the complete work denominator before scores. Include all cold
   loads, complete fresh paired verification, failed/paused attempts, source
   preparation and collection in the measured envelope. The code's 600-second
   execute target is not an execute-plus-verify forecast. No pilot size or
   whole-bank forecast is finalized by this scaffolding.
5. **Collection and primary.** Require every declared block, exact common
   source/model/selection/numerical binding, and the unchanged one-percent
   unsupported allowance. Then independently replay complete collection and
   the unchanged matched primary and surprise companion with 2,000 full
   meeting-cluster refits. Statistical construction proofs do not supply a
   real-bank runtime bound. Every source, score, collection and fit stage
   remains charged to LA under its original ceilings.
6. **Continuation.** A paused predecessor needs an exited exact native owner,
   authenticated phase, immutable checkpoint map and all original pins. Preserve
   all earlier costs and evidence; use a new counted attempt and validate every
   copied checkpoint. A failure is not silently reclassified as a pause. The
   request tool makes no copies and cannot authorize a resume.

The already declared history, window, corpus and laughter-ownership textures
keep their original order, inference and stops. LA2's landed metadata variants
and another builder's sensitivity work are independent; this scaffold neither
restarts nor reinterprets them. No participant identifiers, text or per-act
scores belong in committed admission summaries.

## Required future qualification of this scaffold

Before relying on these request checks, review and run a separate counted
constructed native fixture for exact complete-source recognition; rejection of
partial/unknown/mixed reader selection; source-block order/hash changes;
nested fake completion; missing native phase accounting; and changed paused
checkpoint bytes. Missing measurements and arbitrary model choices must leave
requests nonlaunchable. This document does not claim that proof has run.
