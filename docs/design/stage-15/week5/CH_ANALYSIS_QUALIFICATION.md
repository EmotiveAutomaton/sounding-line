## Sixteen explicit counted stages

The order is one full five-case reference, then CH2, CH3, CH4, CH5 and CH6. Each
card has three distinct attempts:

1. Execute from an empty output and pause after the first whole callback reaching
   five percent of its first recorded loop.
2. Copy the entire runtime-authenticated checkpoint into a new attempt, finish
   execution by revisiting the original loop order, then pause during actual
   fresh verification at the same loop boundary.
3. Copy the second complete checkpoint into a third attempt, preserve the
   completed execution seal, and independently recompute every callback from
   zero. Copied verifier values earn no independent verification credit.

For these frozen cases the boundaries are two of 32 callbacks for CH2/CH3/CH5
and one of 16 for CH4/CH6: 6.25%, the first whole callback reaching 5%. Each pilot
records its actual numerator, denominator and fraction. CH4's first loop is
per-player target fitting and its secondaries; the other first loops are the
original regression/refit resamples. These are not labelled exact-five-percent
samples or whole-card cost forecasts. Large scientific admission still requires
its own measured in-slot pilot and cumulative cost review.

The separately named constructed-only wrapper subclasses progress only in its
own child process. After a real callback has completed and been saved, it writes
a timestamped `owner_cancel` request marked as constructed qualification. It
does not raise a substitute pause exception. The delivered adapter's actual
next-callback request check must save and yield with the exact new-work count.
The original progress class is restored on every return or exception. A request
already present is never overwritten. An external pause outside the declared
boundary stays an external interruption and cannot pass a pilot stage.

The final proof requires the original complete output digest, every original
callback count, zero restored verification callbacks, both native pilot receipts
and exact execution-prefix reuse. Observed setup, callback, between-callback and
final-summary wall intervals are retained; a constructed interval exceeding the
native sixty-second cooperative grace refuses qualification. This timing is
limited to the frozen constructed scale. Full-data solver/setup/summary work
must still establish suitable boundaries; no timing promise is extrapolated.
