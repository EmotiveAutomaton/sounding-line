The IN primary stores each world's fit summary and interval, not its individual
bootstrap values. The unchanged fit function still performs all 2,000 draws and
invalidates a world if any draw loses rank; it never redraws or uses only the
survivors. The qualification successor compares every saved world record after
independently recomputing those draws. It does not falsely claim a saved numeric
per-draw IN bank. SP3 and MD3 retain their existing complete numerical draw banks.

All three parent JSON writers use PID temporary names for files other than
PROGRESS, whereas the current supervisor recognizes UUID temporary JSON names.
A child-local, explicitly scoped publication adapter uses that existing UUID
convention and the same finite sharing-violation retries. It restores the original
callables on exit. No supervisor whitelist, resource limit or numerical function
changes. New JSON uses LF; numeric contents and parsed records are unchanged.
No observed native failure or healing charge is claimed for this static finding.

IN's preserved five-world source/known-answer witness remains an input dependency;
it cannot qualify the full hundred-world grid. New SP and MD constructed sources
are prepared only by a separate bounded counted source handler, using the original
constructors and full case rosters, then independently replayed in a fresh process.
This preparation is charged to the relevant original card/family. Its source files,
expectation manifests, constructor and publication hashes are then pinned by the
qualification attempt. A loose local file is insufficient source evidence.

The one-attempt driver accepts an owner-written exact admission receipt. It names
the attempt, registered module/case, all input hashes, committed design and hash,
separate component and source proofs, actual previous plan/PAUSED digests when
resuming, expected terminal operation, and frozen resource bounds. It requires
hashed cost-accounting evidence and refuses an attempt that exceeds the original
card or family remaining allowance. Known predecessor CPU costs cannot be omitted.
Original source and ancestry pins are revalidated and carried forward. It never
selects the next case, increases a bound, changes a gate, samples data, starts the
next attempt, commits, acknowledges, or admits a human study automatically.

IN and SP first pause after 25 of 500 complete worlds; MD first pauses after 100
of 2,000 participant draws in every declared gamma cell, after complete point/null
setup. Every independent verifier reaches its own saved first-five-percent boundary.
Earlier resource yields remain ordinary paused attempts with their exact costs;
they are not relabelled as the full pilot. A completed qualification chain must
witness both actual execute and independent-verifier pilots, validate all terminal
output hashes and explicit verified true, preserve every predecessor byte, and
observe native owner exit and lease release. Unexpected boundaries are recorded
for owner review and start no successor.

Limits remain IN3.ic 2,500 CPU seconds, IN4.ic 5,000, SP3.ic 5,000, and 1,800 for
each MD3 descendant, within families IN 60,000, SP 40,000 and MD 34,400. These
include preparation, qualification, all failures and full replay. The admission
receipt must use actual remaining balances, not these headline totals as fresh
allocations. Native fixture cost is unmeasured; a full bank that does not fit is
unqualified/cost-held pending the owner's packet-compatible route, never shortened
or called passed. MD3.p's conditional likelihood and all twelve MD3 worlds may be
expensive; the first measured bounded pilot resolves feasibility.
