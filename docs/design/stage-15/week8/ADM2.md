# ADM2 · Archive census and admission

The census includes the archive registry and every additional directory immediately under its open and restricted source areas. Parent folders, aliases, constructed fixtures and original deposits are identified separately. The restricted inventory preserves the directory crosswalk. Each public entry for an owner-only holding uses an anonymous label. A prior-use entry requires a located result in the method archive. “No prior study use verified” records the limit of that search. Archive custody, a source request and a rehearsal alone do not establish prior scientific use.

The counted run reads the original bytes against the acquisition digests, checks the field dictionaries, then repeats the inspections independently. The packet opens sound on the two specified meeting sets only. An additional recording source needs documented separate channels and laughter annotations before it can be listed, and separate sound authorization before it can run.

**Design check.** A changed digest, absent field, duplicate column, unmatched subject or missing reuse terms fails that binding. A constructed ambiguous header must fail. The public inventory projection is tested for omission of private locations. This is a source admission and has no scientific outcome.
