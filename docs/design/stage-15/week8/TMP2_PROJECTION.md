# TMP2 · Original archives and count definitions

Amendment DJ fixes the join, five trait fields and disclosure rule. The archive receipt authenticates one comments ZIP and one profiles ZIP. The sealed job verifies their byte lengths, digests and exact original member names before projecting named columns. It examines the header to bind fields and selects only the author and five trait scores from profiles. The comments projection uses the author, comment ID, UTC creation time, community and body. The installed image must be on CPU with only its loopback interface. [Reviewed mapping](TMP2_MAPPING.md).

A profile key must be unique. Check each trait separately over present values. Native blanks and the missing strings NA, N/A, NaN, null and None are absent. Other values must be finite and on the approved 0–100 scale, with at least a tenth above one. Only five complete scores qualify an author. The provider reports that its nominal scale combines raw scores, percentages, percentiles and values mapped from descriptions. A successful numerical range check cannot recover which transformation an individual used. [Gjurković et al., §3.2](https://aclanthology.org/2021.socialnlp-1.12/).

Match the five named traits as whole words, case-insensitively. A distinct trait qualifies for the reporting pattern when a digit occurs within the following 40 characters. The community exclusion applies across all authors. Apply both community rules before dropping residual reporting or test-naming comments. The fixed test-name vocabulary includes personality test, inventory, questionnaire and assessment, MBTI, Myers–Briggs, Big Five, BFI, Five Factor Inventory, NEO-PI, NEO-FFI, IPIP, HEXACO, Enneagram, Keirsey, Jung Typology, Socionics, 16PF, 16Personalities and MMPI. A comment can meet more than one criterion but enters a count only once at that step.

Count words on available original text. Empty bodies and platform deletion markers provide no text. Retain at most 1,000 surviving comments per scored author, in UTC creation order with comment ID breaking exact ties. Check the 100-comment and 5,000-word floors on those retained comments. Reject ambiguous source keys. Rebuild the selection independently. For the reader job, emit the selected named fields solely in temporary storage inside the seal.

The five prospective count rows are scored authors, kept authors, communities excluded by a scored author's reporting comment, communities matched by name, and comments dropped under the residual rule. Each count carries the actual number of identified people contributing to it. Use the reporting people for the third row, authors who posted in name-matched communities for the fourth, and authors of the dropped comments for the fifth. Apply the distinct-person membership rule and the DJ suppression rule to both the measures and denominators. Prioritize the packet's order when two distinct counts conflict. Only the numeric row code, count and actual person count can leave. No community name, participant key or text enters the return.

**Design check.** Construct scored and unscored writers, a reporting group shared across writers, a type-named group, a residual test reference, ties, a truncated history, absent fields, mixed units and out-of-range values. Check both native error codes and the unchanged installed gate. The count job reserves 4,000 CPU-seconds within TMP2's 20,000-second row allowance.
