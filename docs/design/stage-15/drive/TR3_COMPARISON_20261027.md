# TR3 carryover comparison: operational freeze

This implements Week 3 TR3 after discovery-only feature selection and before
reading reserved-writer feature outcomes. It is descriptive on the already
exposed CoAuthor corpus. It does not open TR3c or any Tier 4 outcome. The
October 27 approval retains the original 7,200 CPU-second ceiling and forbids
further automatic repairs. All earlier failures and the repair breach remain.

## Complete source and exposure

Retain all 1,399 sessions and the frozen 61-writer WB1 split. Reuse the completed
discovery human counts unchanged; count the reserved writers with the same
frozen production counter. Restrict the saved feature bank to the completed
discovery selection. The denominator remains every user-inserted Unicode
character, including later-deleted text. Empty sessions remain with explicit
undefined rate support. Preparation emits counts, not comparative scores.

For each original displayed menu, count one exposure per alternative containing
a feature, irrespective of its repeated occurrences within that alternative.
A reopened menu adds no new alternative. Retain empty and unanchored reopen
events without invented offers. All shown alternatives enter exposure. Only
the option identified by canonical reconstructed insertion counts as accepted
or edited production. Unchosen alternatives on an accepted menu are other
exposure, not accepted and not a dismissed menu. Options on a usable dismissed
menu count as dismissed. Ignore and unknown handling remain separate. The
logged selected index is never consulted. Bind the canonical record to the
hash in the independently verified source lineage, checking exact menu options
and handling against the completed exposure archive.

## Matched comparison

Build histories using sessions whose end strictly precedes the target start.
Retain touching/overlapping histories as unsupported chronology when they make
the target writer's earlier record ambiguous. Retain all census rows, exclusion
reasons and unmatched features. For each reserved target session, eligible seen
features occurred in that writer's strictly earlier offers but never in her
strictly earlier completed human production. Earlier API insertion is not
human typing. Session index is the count of strictly earlier sessions; practice
is their total typed-character count.

For each seen feature, collect the prompts on which the writer previously saw
it. A placebo must come from another writer's offer on one of those exact
prompts, from a session ending before the target begins. It must have the same
feature family and frozen discovery-frequency decile, and must never have
occurred in the recipient's prior offers or prior human typing. Here 'never'
means before the target session; future records cannot determine eligibility.
Use every distinct qualifying placebo feature with equal weight, then weight
each supported seen feature equally. Do not tune matching from target outcomes.
No match is unsupported, not a zero. Report the match census before interpretation.

The primary is the seen feature's count minus the average count of its matched
placebo features, per 10,000 target-session typed characters. Average supported
features within session, sessions within writer, then writers equally. Comparing
both arms in the same session conditions on the exact prompt, session index and
practice, as well as all other additive session-level baseline differences.
This is session pairing, not a claim that effect heterogeneity is removed.

The whole-session primary retains any current-session re-exposure. Predeclare
a diagnostic excluding seen-feature pairs reoffered during the target session,
with changed support explicit. This does not replace the primary and does not
make the observational contrast causal.

## Required secondary contrasts and uncertainty

Report dose as the slope of the primary feature-level excess rate on
`log(1 + prior offer exposures)`, centered within each target session. Equal
session weight within writer and equal writer weight apply; invariant dose has
no slope support. The dose definition counts alternatives, not characters.

For accepted minus dismissed, accepted-only means at least one canonical
accepted/edited exposure and no dismissed exposure; dismissed-only means at
least one dismissed exposure and no accepted/edited exposure. Mixed and
other-only exposure remain in the primary and are separately counted. Match
each accepted-only feature to all dismissed-only features in the same family,
frequency bin and intersecting earlier exposure prompts. Apply the same paired
rate and writer aggregation. Report dismissed-only minus its never-seen
placebos separately. Missing secondary support does not become a null.

Use 2,000 real-writer bootstrap resamples, seed 20261026, for paired 95 percent
intervals, with all a writer's supported session data kept together. Use 200
within-writer, within-prompt permutations of complete target-session outcome
vectors and their denominators against fixed histories and matches. Singleton
blocks remain fixed and the effective permutation support is reported. This
reference tests association beyond stable writer/prompt background under its
exchangeability assumption; it is not a randomized exposure experiment.
Report its mean, central 95 percent band and plus-one one-sided tail probability.
If there is no permutation variation, label reference support absent rather
than manufacture a passing control.

Before corpus inference, known-answer calibration must exercise zero carryover,
positive and negative planted carryover, fixed writer/prompt nuisance differences,
unmatched and zero-denominator cases, chronology boundaries, and canonical
accepted-option attribution. A failed instrument is retained and stops this
continuation; no repair or renamed retry follows automatically. Positive routing
requires the primary interval wholly above zero and a passing reference;
an entirely negative interval is a negative direction, and an interval spanning
zero is not detected. Missing sensitivity or reference support is explicit and
prevents a licensed positive or negative claim. No equivalence claim is licensed
by an interval spanning zero. Full secondary and control results must be recorded
before final reporting. Preparation alone licenses no scientific interpretation.

Stable personal vocabulary, same-session re-exposure, opportunity selection and
imperfect frequency matching remain rivals. The test measures recurrence in
recorded typed production, not unnoticed adoption, attention, automaticity,
belief change or indoctrination. A positive freezes the proposed TR3c route;
it never spends the locked holdout this week.
