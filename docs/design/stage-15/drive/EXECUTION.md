## Evaluation and early stopping

P4/G3-A use the same chronologically ordered writer/session roster, with each
writer's earliest 60% of sessions for training, next 20% for calibration and
last 20% for scoring (at least 3/1/1 sessions). Strictly earlier sessions alone
enter each history; no future resolution or same-timestamp unfinished session
enters a prediction. The globally pooled fit uses only training rows. Writer
intercepts and hyperparameters are fitted on training/calibration, never the
scored tail. Tuned choices are frozen before paid labels; neither arm gains new
fitting data at an interim look. Report every eligibility exclusion and support.

Random provider labeling order is separate from prediction chronology. Freeze
writer-stratified acquisition blocks before dispatch. Evaluate both arms on the
identical labeled scoring block; session means give each session equal weight,
writer-cluster uncertainty accounts for repeated sessions. No successful-only
deletion: invalid labels receive a missing indicator and frozen neutral encoding.

G3-A stops for futility at 20% if z < -0.5 and at 50% if z < 0. It cannot stop
early for success. A nonpositive effect with zero standard error stops; an
undefined statistic stops as invalid. The terminal one-sided test of gain > 0
is distinct from the useful-gain margin of 0.01 half-Brier. These are resource
decisions, not proof of no effect. Validate the fitted clustered procedure on
target-matched constructed worlds before interpreting its error rate.

Each local card names one primary contrast and direction before execution, plus
its fixed initial sample and at most one independently frozen extension. A
three-hour implementation allowance is not an arbitrary statistical look.
Negative/null branches stop; marginal/positive branches may use their one
predeclared extension. Always report the original and extension separately and
the whole specification curve. Ordinary exploratory intervals are not adjusted
for this selection. No automatic threshold relaxation, repeated-seed rescue or
generic retry of failed instruments. Further cloud spend needs evidence of
progress as well as the separate dollar authorization.

## Measurement corrections

- V1 uses separate outcome, process-identity and text/adaptation constructions.
  Redrawing outcomes cannot null existing process identity. Recompute all lags
  recursively and refit. Known four-class gain is half the mean squared distance
  between true and reference probability vectors. Ten worlds are a coarse check.
- V2 reports exact half-Brier, raw reliability/resolution/uncertainty, and the
  binning residual including forecast/outcome covariance. Fixed decile bins are
  merged deterministically with an adjacent bin until size >= 2; exact vector
  bins retain singleton status and do not get a fabricated correction. Corrected
  terms are diagnostics under iid assumptions, not a cluster-valid unbiased
  decomposition. Use writer-cluster uncertainty for empirical contrasts.
- P1 pins tokenizer and model files. Compare scores on common UTF-8 byte spans,
  retaining native token losses. Token boundaries cannot define cross-reader
  observations. Whole-document conditions that exceed a model's context are
  unavailable, not silently truncated. c2 uses the fixed target reader's last
  100 context tokens and is explicitly reader-specific; compare common eligible
  rows. c4 has a separate 1,024-token history budget and explicit packing ledger.
  Pilot actual tokens and speed before extending the full inference workload.
- P2 preserves UTF-16 replay and persistent provenance. Delta insertions are
  events, not invented keypresses. Record codepoints, UTF-16 units, multi-character
  inserts, deletions, API text, source clocks, keyboard and hover events separately.
  Ignore handling has no directly observed mental decision time: distinguish
  observed selection/dismissal latency from a first-edit proxy and censored end.
  T1's timing convention and missing/proxy counts accompany the reference.
- P3 native agent references are blind to classifier output and disclosed as
  agent labels, not human truth. Freeze ambiguity/category policies before
  classification. A failed category is disabled; any coarser fallback has its
  own prespecified reference rule. Constructed success and model agreement do
  not establish natural-data accuracy. Fit protected-variable candidates on
  separate sessions from restoration scoring.
- D6 does not equate no hover with no exposure. Audit assignment and include
  keyboard navigation, default highlighting and latent-exposure sensitivity.
  D16 identity is not uniquely cognitive; D23 decline is not identified
  uncertainty reduction; D24 closure is not an isolated drive intervention;
  D14 restoration is not by itself a controlled internal set point. Preserve
  these theoretical questions and test rival explanations.
- D27 reports out-of-sample improvement over each baseline, not an AUC/R-squared
  ratio described as an information fraction.
