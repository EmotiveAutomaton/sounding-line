# FIC1 exact reassignment reconstruction and cost probe

The commissioned identification null shuffles writer labels within prompt and
rebuilds profiles. Saved observed vectors cannot stand in for that operation:
the session membership, chronological prompt split and boundary word selection
can all change. This component reconstructs those inputs without computing any
identification score, control verdict or probability.

Use the complete sealed FIC1 occurrence records and session features. Each
assignment retains every session and each writer-label count within genre and
prompt. Recompute the existing whole-prompt chronological split for each
reassigned writer within genre. Pool the exact occurrence prefixes at the
original 500, 1,000, 2,000 and full word budgets using the unchanged selector,
count denominators and interval medians. Pool final-document counts and accepted
character share from those same assigned sessions. An assignment without enough
sessions or disjoint prompts stays explicitly unsupported, as does a short
profile. No redraw, padding or successful-only bank is allowed.

The identity assignment must reproduce every original saved profile, ordered
membership, word count and prefix feature exactly before any shuffled preparation.
Known-answer validation covers exact parity, word quotas, count conservation,
order invariance, changed prompt-half chronology, missing support, altered
bindings, serialization, reentry and fresh native reconstruction.

The bounded corpus probe reconstructs the identity assignment and the first
within-prompt shuffle at seed 20261026, then repeats all work in a fresh process.
It records separate loading, identity and shuffle CPU costs. One shuffle is a
timing observation, never the required 1,000-draw scientific reference. The
complete statistical design still requires its observed/control consistency,
approved independent-donor correction, nuisance refits, fixed-support scoring,
paired uncertainty, length-trend gate, calibration and full-cost admission.
AUTH remains separately gated and no human scientific score is inspected.

The original FIC1 ceiling remains 7,200 cumulative CPU seconds. Prior completed
preparation charges and reserves are 1,750.953125 seconds. Add a 120-second
construction/test reserve; cap constructed native validation at 120 CPU seconds
and the single-shuffle corpus timing pass at 300 CPU seconds. Both use one
numerical thread, 4 GiB projected RAM and at most 256 MiB output. Completed and
failed prior evidence remains immutable. This is the next commissioned component,
not another attempt to heal a scientific gate.
