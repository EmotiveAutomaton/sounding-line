## DESIGN CHECK

LESSONS sections 3–5 reread for this build. Under null and alternative, every
source session and writer remains. Changed completion, plan, dictionary or unit
bytes, duplicate identities, nonfinite timing and inconsistent counts refuse
completion. Empty or short text yields explicit unsupported features, never
zero-filled evidence. Missing timing remains missing. No scientific gate fires.

Reuse the original PMAP word, punctuation and bigram dictionaries and its
frequency/median definitions. Count the complete final document separately from
surviving human-only groups. Tokenize each human group independently so a model
or prompt gap cannot create a word. Keep full production counts (including
later deletions) separate from surviving human text. Denominators include words
outside the fixed dictionary and all punctuation under the original tokenizer.

For later equal-length comparisons, also retain deterministic prefixes of 32,
64, 128, 256, 512 and 1,024 surviving human words. Each prefix ends at its final
word; punctuation before that boundary remains. A short session retains its
full count and an explicit missing prefix. These are candidate representations,
not a selected length or a performance-based choice. No identification is run.

Retain canonical handling counts and proportions for accept, edit, dismiss and
ignore, plus the original timing arrays and their median features. Preserve
model share, source chronology and provenance counts unchanged. Source origin
is not cognitive contribution. No participant-level records leave ignored raw
storage; public receipts contain aggregate support and validation only.

Known-answer checks cover group boundaries, Unicode, out-of-dictionary words,
prefix boundaries, empty text, absent/invalid timing, canonical handling,
source tampering, immutable reentry and a real completed producer integration.
A complete constructed native execution and fresh replay precede production.
Production verification reconstructs every feature and support entry from the
authenticated source again in a separate native process.
