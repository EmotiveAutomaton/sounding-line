# V2 empirical reliability and resolution

DESIGN CHECK: LESSONS 3–5. Deterministic perfect forecasts have zero loss;
constant forecasts have zero resolution; within-bin covariance may make the
binning residual negative. Invalid forecasts never gain a valid score by being
silently normalized. Exact reconstruction is required, not a fitted tolerance.

Apply the tested decomposition to the complete retained Phase 0 prequential
population, personal-frequency and backbone forecasts, and separately to the
aligned Stage 14 reader comparison: all four raw 27B history conditions and
both complete repaired calibration methods, corrected and stacked. These are
different cohorts and are never pooled. No old model is refitted or called.

Report exact half-Brier, fixed merged-decile decomposition and exact-vector
decomposition for every arm. Singleton exact-vector bins keep their missing
finite-sample correction. Corrected reliability is an iid diagnostic only;
the uncorrected terms plus the covariance residual reconstruct the actual score.

Invalid reader predictions retain the original system loss of one. Their
probability decomposition is reported only on valid rows with its denominator;
no implicit uniform-vector repair. Stacked predictions remain valid with the
original frozen baseline fallback. Paired system-score gain uses every aligned
row against population forecasts (Phase 0) or backbone forecasts (reader cohort),
with 2,000 writer-resampled bootstrap draws, seed 161016. This is a descriptive
uncertainty interval conditional on saved fits, not an optional-stopping p-value.

The entire curve is retained; no best arm selection or extension. This shared
diagnostic changes no scientific admission. Whole-reader fits, chronology,
exposed-data and calibration-model limitations remain inherited. CPU only,
one numerical thread, one-hour computation ceiling, six-hour resource wait.
