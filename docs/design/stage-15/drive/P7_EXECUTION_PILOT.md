# P7: CPU scoring instrument and execution pilot

Frozen before dispatch on October 18 under the October 17 batch plan's
unconditional P7 prerequisite. This is an execution and numerical-validity
pilot, not a scientific contrast. No family result or admission follows.

P7 supplies GPT-2 medium per-token losses for the writer-typed production
ledger and Jester joke texts. Its stronger population reference is required
before D33's single registered extension. D36 still needs its ratings adapter
and its separate rereading comparison; this pilot completes neither consumer.

Authenticate the verified P6 recovery, its original plan, bound roster and
every indexed score file. Replay each selected source log to recover the full
visible prefix at the produced token's completion event. Retain revised word
occurrences and punctuation under the original production ledger. System/model
text in that visible prefix remains context, never a newly labelled typed target.
Missing occurrence identity or incomplete prefix coverage refuses execution.

Use the independently verified 150 original Jester texts from the pinned
Berkeley release. No ratings are read. Select the median typed session by
production-token count, breaking ties by frozen session identity, and the
longest joke by character count, breaking ties by string joke identity. This
selects 306 targets in each domain before scoring. These cost-based selections
are not representative scientific samples or a guarantee of corpus throughput.

Load the already cached GPT-2 medium snapshot at revision
`6dcaa7a952f72f9298047fd5137cd6e4f05f41da`, CPU float32, evaluation mode,
two numeric threads. All six model/tokenizer files and package versions are
bound. Cache symlinks are checked for snapshot membership and their resolved
bytes are hashed. No download, GPU access or paid call is part of this runner.

Tokenize the complete visible prefix plus target. Prepend the model's end token;
left-truncate only at its native 1,024-token context. Sum conditional negative
log probabilities of native tokens overlapping the target and retain every
native ID/loss and omitted-prefix count. Boundary-spanning native tokens are
included whole. This is a contextual language-model feature; it is not a
normalized distribution over the word vocabulary or a human probability.
Do not silently use it as one in downstream interpolation.

Reuse only an identical native-token prefix, cropping the key/value cache and
recomputing the boundary prediction. Save immutable, hashed blocks of 50 targets
with source-prefix bindings. Resume authenticates all saved blocks before model
loading, skips their scoring, and preserves their bytes. Partial blocks or
changed receipts fail closed. A resource/forecast yield ends at a saved block.
The first pilot tenth estimates the selected pilot's duration; its eventual
corpus projection scales each domain separately by its frozen target count.
That projection excludes final verification and does not admit main.

or an alternative scientific effect, exact-input cached and fresh CPU forwards

immutable reentry and the real counted native runtime, without changing the
production model identity gate.

admission and retained evidence; no automatic launch or retry is implemented.
