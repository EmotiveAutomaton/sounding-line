# P3c saved edit pairs and blind calibration preparation

DESIGN CHECK: LESSONS sections 2–5 reread for this design on October 27.
The null and alternative have the same complete source population and selection.
Missing identities, duplicates, changed bytes or failed reconstruction refuse;
mixed provenance, empty text, identical pairs and repeated contents are counted,
never silently removed. Source validity licenses no intent label or effect.

Authority is Week 3 P3c: the shared CPU edit-intent pass with a four CPU-hour
ceiling and two engineering repairs total. This preparation uses the completed,
independently verified P5 sentence/edit archive. It neither retries nor depends
on the exhausted newer accepted-span extractor. P5's exact affected before/after
sentence windows and session/ordinal keys remain the event unit. All primary
sessions and every P5 edit are retained, including model-linked, own-text and
other/mixed origins; the source's earlier deterministic labels, cosine distances
and embeddings are not input features or selection criteria. The census reports
the source population, not a claim that every historical action was an edit.

Sort sessions and their edit ordinals. Freeze one permutation of every event key
with Python Random seed 20261026. Its first 200 events form the calibration set;
retain repeat contents and disclose their distinct count. A separate blinded file
contains only random-order aliases and the complete before/after texts. Keep its
identity map private. Agent annotation will use written criteria, be explicitly
agent-made and frozen before classifier predictions. The first 1,000 canonical
events form the packet's cost timing set. If timing requires sampling, the later
cost-admitted sample is a prefix of the already frozen random permutation; no
outcome can choose its membership. Do not silently truncate input text or omit
edits from the census. Model tokenization and its coverage require their own
explicit review before timing.

This step produces no labels, classifier calls, agreement statistic or downstream
comparison. The packet's meaning-changed versus other Cohen agreement gate of
at least 0.6 remains unchanged and untested. Download/model provenance, written
label criteria, blind annotation, native model validation, measured complete-run
cost and inference remain implementation work. Failing the later gate does not
authorize paid transfer without the existing destination approval.

Known-answer tests cover preservation across provenance classes, Unicode and
empty/unchanged pairs, exact sample size and order invariance, duplicate/schema
refusal, forged source receipts, immutable reentry and full output mutation
refusal. A constructed native handler run and independent full replay precede
the full saved-source run. The latter authenticates the original completion,
index, every session file and original plan pins; it verifies its full source
population and reconstructs every output in a separate native process.

Charge construction/tests a 120 CPU-second reserve plus measured native and
full preparation time against the original 14,400 CPU seconds. The source pass
has a maximum 600 CPU seconds including verification and a 1,800-second safety
wall limit; it does not spend the remainder on a model without measured admission.
One numerical thread, counted lease, resource floors, hidden native launch,
terminal monitoring and independent verification use the existing Week 3 harness.
No GPU, paid call, population reduction or changed scientific gate is authorized.
