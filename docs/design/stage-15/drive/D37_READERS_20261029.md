## Readers and fitting

All four handling classes are always present in probability arrays. Each
recipient uses the unchanged pooled training sessions ending before their first
calibration session. Page and process readers are multinomial logistic models
using the existing P4 pooled objective: mean negative log likelihood plus
0.005 times the squared non-intercept coefficients. Standardization and the
page embedding PCA fit only training rows; PCA keeps up to 16 coordinates,
seed 20261026. The page reader uses only the 53 isolated content scalars and
embedding coordinates. The process reader uses the six prepared prefix fields.
No calibration or test outcome enters either fitted reader.

The person reader uses a training-only version of V3's response-scale reliability:
the nonnegative crossed moment fit for writer, prompt, decoding setting and
writer-by-prompt, with prompt main variance excluded from the denominator.
Use the four-coordinate trace ratio, not a latent-logit reliability. Authenticate
D15's complete row file solely to join setting and verify canonical handling;
do not consume its through-resolution timing features. Undefined or aliased
training reliability refuses the complete comparison rather than dropping a
recipient. Structural constant groups follow the original moment fitter.

Convert reliability r to a fixed prior count (1-r)/r. This is an explicitly
declared shrinkage convention, not a consequence of the Gaussian moment model.
The training class frequency is the prior mean. Add the recipient's previously
resolved handling counts and normalize. At zero reliability use only the
population mean; at unit reliability use empirical history, with the population
mean if no history exists. History follows P4: earlier opens only, resolved
before this open, and other sessions must have ended before the current session
started. Earlier calibration and test decisions may update this observed prefix;
neither fit parameters nor prior reliability are refitted. This tests a handling
history person entry, not the broader production entry proposed in G222.

Each recipient's calibration sessions choose the best single entry by
equal-session half-Brier; exact ties use page, person, process order. Fit one
nonnegative three-weight simplex combination by the same calibration loss.
Enumerate all nonempty active faces, solve their equality-constrained quadratic,
and certify feasibility and the global convex first-order gap. Rank only
certified solutions. Test labels never select an entry or weights. Freeze these
choices for the scoring tail. Any identical-reader contrast is exactly zero.

## Comparison, controls and continuation

The primary is equal-session test half-Brier of the calibration-selected best
single entry minus that of the combination. Writer-cluster resampling uses
2,000 draws and seed 20261026, conditional on fitted forecasts. Report each
entry's loss beside the comparison. Positive, marginal, null, negative and
invalid retain the packet's exhaustive signed states. No V5 headroom division.

The outcome reference uses 200 within-writer permutations, seed 20261026,
rebuilding histories, training-only reliability, both fitted readers, selection
and combination for every draw. Report its mean, SD, quantiles, predicted-
direction permutation probability and the inherited quarter-SD bias flag.
The reference preserves person marginals and is not assumed to remove all
writer information. A biased reference restricts wording to descriptive only;
it is not repaired by reducing permutations or changing an observed threshold.
No fake-writer control is substituted for this forecast comparison; any later
person-specific causal claim would require its separately matched contrast.

Before human inference, freeze and run complete target-matched constructed
calibration, including no complementary signal and complementary entries.
The native fixtures here validate arithmetic and chronology only and do not
replace that campaign. The original positive/marginal extension, combination
weights versus prior session count, remains to be frozen before its outcomes.
No post-outcome bin or fit choice is authorized by this document.
