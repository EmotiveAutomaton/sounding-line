## DESIGN CHECK

LESSONS sections 3–5 reread for this build. Under both null and alternative,
all 1,399 prepared sessions and 61 writers remain. Wrong identity, chronology,
changed source bytes, malformed UTF-16 coverage, or disagreement with retained
source features refuses completion. Empty human spans and unknown API origin
remain explicit, not silently excluded. No scientific acceptance gate is run.

Authenticate completed PMAP-recovery and its original input plan. Reconstruct
each complete process row from the raw logs through its retained recovery
adapter and require exact agreement with the completed row. Independently
rerun the original P2 timeline replay and require equality of the whole archived
timeline, after its authenticated identity fields are applied. P6's surviving
typed token sequences must equal fresh extraction from those final spans.

Preserve full final text, source spans, contiguous final typed groups with exact
UTF-16 offsets, and the production token ledger separately. Never concatenate
human spans across intervening model or prompt text to create n-grams. Adjacent
human insertions are joined only when they are adjacent in the final document.
The production ledger includes later-deleted words and is not final typed text.
The process row retains its original timing validity and missingness semantics.

Count surviving codepoints and UTF-16 units by prompt, typed, accepted,
accepted-edited and unknown-API origin. Accepted-edited denotes surviving
original model characters from a touched insertion; newly typed replacements
remain typed. Model share is surviving accepted plus accepted-edited codepoints
over nonprompt final codepoints. It is absent if that denominator is empty or
unknown API characters survive. Retain the known accepted fraction separately
when provenance is incomplete. This is recorded text origin, not intellectual
contribution, cognitive work or human endorsement. Prompt text remains explicitly
available for later controls, never silently treated as the writer's own text.

Known-answer tests include non-BMP characters, edited model spans, adjacent
versus separated typing, zero-length support, unknown API provenance, mismatched
offsets and source joins, whole-timeline reconstruction, immutable reentry,
tamper refusal and resource-boundary yield. A complete constructed run through
the counted coordinator and a fresh native replay precede full-corpus dispatch.
Corpus verification reconstructs every complete session again, not just hashes.

## Budget and next boundary

Retain the fixed 3,600 CPU-second probe total. Charge a 120-second build reserve,
twice targeted-test elapsed time, all native checks, execution and verification.
Constructed cap: 60 CPU seconds. Corpus source cap: 3,000 CPU seconds and 4,500
wall seconds. The original PMAP source pass took about 867 wall seconds; this is
context, not a measured CPU forecast for the new replay. At the first tenth,
project both complete passes with an additional factor of two and yield if the
cumulative allowance would be exceeded. Check resource/yield markers at every
session boundary and preserve all partial source checkpoints on refusal.

Bins, length matching, writer galleries, estimators, complete inherited controls
and constructed scientific calibration remain a separate frozen build. There
is no identification score, attenuation result or causal inference in this step.
Raw text, identities and per-session records stay under ignored raw directories.
