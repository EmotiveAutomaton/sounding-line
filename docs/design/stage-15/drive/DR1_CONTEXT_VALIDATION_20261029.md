# DR1 independent-context validation and measured admission

This implements component 3 of [the registered supplement](DR1_WEEK3_CONTROLS_20261029.md)
under the same Week 3 section 6 allowance. Source transformations and inference
reuse the already validated WA0.h1 functions. The operator is the mean of
per-session rates, retaining all words and punctuation in each denominator;
it is explicitly distinct from DR1's original pooled counts. All original
eligible writers and sessions remain. A missing donor prompt or fixed gallery
is unsupported, not a license to reduce the population.

**DESIGN CHECK:** LESSONS sections 3–5 and CONTROLS sections 1–7 re-read this pass.
Freeze three complete 12-writer, four-prompt, two-repetition worlds. Constant
features and prompt-only features must not clear both references. Stable
person fingerprints added to the same prompt features must clear both.
Each world must complete every one of 1,000 within-prompt/role permutations,
2,000 bootstrap draws and three writer-role rotations. Any failed requirement
holds human dispatch, with the failed evidence retained. This establishes
finite known-answer behavior, not a universal false-positive rate or human
mechanism. Donor/probe disjointness, fixed population, assignment margins and
missing-support refusal are separate targeted checks.

writers, full features and galleries, all three rotations and 100 permutations
per rotation. It emits no scientific verdict: its raw private detail is retained
for exact replay only. Project the full 1,000-draw run as ten times the slower
full timing pass, times two for execution/replay, times three for uncertainty,
plus 120 CPU seconds. Timing dispatch has a 1,800 CPU/wall second maximum.
The complete run requires a hashed cost landing and all prior charges/reserves
within both the declared CPU equivalent and remaining section 6 wall allowance.
No attempt obtains a new ceiling by changing the runtime field name.

diagnostic. Only independent donors enter the corrected comparison. The
original random-order rank supplement, retrospective scope and chronological
routing default are retained; these disjoint-profile controls do not turn its
overlapping endpoint into held-out reading-policy performance.
