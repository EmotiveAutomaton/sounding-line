# FIC1 complete source preparation

DESIGN CHECK: LESSONS sections 2–5 reread October 27 for this implementation.
The null and alternative require the same exact source population, original
prompt halves and complete typed-production records. Changed or missing records,
duplicate identities, mismatched prefixes, incomplete final provenance and
cross-half prompt leakage refuse the source. No identification gate is tested
or waived by this preparation.

This implements the source step of the commissioned Week 3 FIC1 card. Preserve
GEN1's 24 writers and 990 selected sessions and each session's original genre and
prompt half. Restore each selected session's complete P6 typed-production token
ledger, including occurrences later deleted, without the old cross-genre word
quota. Keep that quota and verify its exact original prefix for comparison.
Retain the 409 other completed primary sessions in a separate source census;
they are not silently substituted into this fixed-cohort variant. The larger raw
archive must cover the complete primary population, as its validated predecessor
already requires.

Join the same sessions to the independently completed final-document export.
Require exact writer/session/prompt equality and a complete contiguous provenance
partition whose text hash matches. Keep prompt, accepted model and typed spans
explicit. Final documents are mixed-provenance objects, not human-only texts.

The prepared token ledger is a production record, not a whitespace-preserving
reconstruction of continuous prose. It does not become an AUTH provider payload
by joining normalized tokens. AUTH's exact visible text, pair sampling, paid
ordering, concrete transfer admission and known-answer rung remain separate.

Write one sealed local record per selected session, a complete index, the
unchanged writer/genre/half session memberships and full/matched length counts.
The source contains no newly fitted feature, similarity, accuracy or genre
contrast. All participant text and identities remain local and out of public
reports. The forthcoming comparisons must retain the packet-wide controls and
approved independent-donor context correction, explicit length adjustment and
their own complete cost and validity admission. Preparation does not repair the
original failed context reference.

Known-answer checks cover restoration beyond matched prefixes, later-deleted
typed occurrences, Unicode, mixed final provenance, legitimate upstream-only
records, source order invariance, invalid identity/count/split/provenance refusal,
source seals, full handler reentry and changed-input/output refusal. A counted
native fixture must independently replay before corpus preparation is dispatched;
the corpus preparation must likewise replay every selected session in a fresh
process before landing.

Use the existing one-thread CPU runtime with a counted lease and all four urgent
terminal watches. Charge 180 CPU seconds of construction/test reserve to FIC1's
original 7,200-second ceiling. Native source validation has a 120-second allowance.
After it passes, the full source preparation has a 600-second combined execution
and replay allowance within the same cumulative ceiling. These are source steps,
not full-study cost admission or a new scientific follow-up.
