# B2: refusals to trade, before outcomes

DESIGN CHECK: LESSONS 2-5 and CONTROLS 6-7. A fair-coin chooser has
never-trading probability 2 times 0.5 to the number of choices. Different
exposure counts can create different apparent rigidity without different
preferences. Signed constructed cases must recover direction; equal dimensions
must not become positive identity evidence. Missing support is not a null.

Use Awad et al.'s all-session SharedResponses archive, CC-BY 4.0, official
SHA-256 `4c8e32872b432831a4b8670b3a2b4b797f4af8f9b39543b784a939aaf49bd7a9`.
The first-session and demographic-survey files are not substitutes. Read only
response, session and fingerprint identifiers, scenario type and strict type,
attribute level, intervention and saved choice. Fingerprints are linkage keys,
not established people; no demographics or names are read or published.

Reconstruct pairs by response identifier. Require exactly two rows, one saved
side, opposite intervention values and consistent user/session identities.
Character dimensions additionally require both type fields to agree and
complementary declared levels. Retain all orphan/invalid counts. Species,
gender and fitness use their generated scenario types; intervention uses every
valid pair. No win/loss, response row or saved label is guessed.

The case is at least 1,000 fingerprints with at least two sessions and at least
three complete scenarios on each of species, intervention, gender and fitness.
Report counts before this common-cohort restriction, including all users with
three scenarios on each dimension. Failure is design cannot test.

Report the all-observed never-trading rate and its mean coin-flipper expectation
for each dimension. The primary controls exposure: within each common user,
draw the same number k of scenarios from each dimension without replacement,
where k is that user's smallest dimension count. Use seed 20261106 and sorted
identities. Drawing positive counts hypergeometrically is exactly equivalent
to a uniform subset of binary choices. The per-user contrast is the mean
never-trading indicator for species and intervention minus that for gender
and fitness. Keep all four component rates beside the primary.

Use a 2,000-draw fingerprint-cluster percentile interval. The practical bar is
five percentage points. Supports the specified differential-refusal prediction
if the whole interval exceeds +0.05. Against if the whole interval is below
zero, or entirely inside [-0.05,+0.05]. Otherwise inconclusive. A homogeneous
contrast uses a bounded-mean Hoeffding interval instead of a zero-width bootstrap.
This observational comparison cannot identify terminal identity or prove that
no possible offer would trade; repeated choices in these finite scenarios are
the estimand. No causal identity wording is licensed.
