## Scope and next gate

No human text or identity goes to a provider. No paid calls or automatic cloud
submission occur here. Passing questions can enter a separately frozen local
10% feature screen only after real-data, backbone, Ghost and holdout/error-control
gates. A later cloud comparison needs its own forecast and shared guard
reservation under the existing $50 campaign cap. A failed question stays disabled.

The single finite worker has a 12-hour ceiling, RAM/commit floors 8 GiB, disk
floor 20 GiB, one CPU thread, source/model/runtime pins and an exclusive lease.
Each question and the queue have terminal/failure/disappearance watches. The
normal six-hour inspection remains; there are no extra ETA wakes. On completion,
replay the full recorded responses and perform the internal write-through before
ACK. CPU time is expected to be roughly seven hours from the existing 200-item
Q5 measurement; this is an estimate, not a deadline or throughput guarantee.
