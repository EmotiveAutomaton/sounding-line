# Native shared-reader consumer

The actual Ghost V19 export supersedes the provisional byte-GRU interface. It
contains frozen 32-dimensional transformer and 38-dimensional recurrent readers
of observable endpoint histories. Their output is four distributions over eight
endpoints. It is not a local-goal or preceding-operation head. Ghost owns both
consumed sequence-model settings; this consumer trains neither again.

This implements the commissioned source/reference review, using the complete
tiny-reader, causal-fixture, original/alternate-site alignment and practice
packets. Source and protocol archives, plans, native accounting, deterministic
files and input hashes are copied into an immutable private snapshot before
dispatch. Workers consume that snapshot, not a changing sibling checkout.

Three serial CPU cards use one numerical thread and below-normal priority, with
zero GPU or cloud calls. Each reserves at most 1,800 CPU seconds and 3,600 wall
seconds under the original week contract. Failure retains the entire attempt;
source disagreement does not trigger a new fit or an automatic retry.

1. Reconstruct every frozen model's original development forecasts, then every
   challenge forecast and exact history-conditional reference. Recheck the
   original per-fit capability margins; do not substitute a pooled pass. Both
   input-only copies and evaluator arrays retain their separate roles.
2. Reconstruct the supervised probe fits using augmented least squares, all
   seven intervention arms, both allowed access sites and every saved score.
   Ordinary capability does not establish selective use. The existing source
   admission fails to support joint purpose/belief composition, so this consumer
   cannot manufacture a composition-ready marker from successful replay.
3. Reconstruct all practice, identical replay and demonstration count updates,
   saved production policies, known-law values, coverage and full scores.
   Evaluate the saved policy unchanged, admitting numerical near-ties rather
   than replacing its actions. Verify native trajectory support and the exact
   replay identity. This supplies production support, not the missing
   expertise-by-inversion/observation-quality contrast.

These are infrastructure/source-consumption cards, not fresh independent
replications. The native mathematical port shares Ghost's source; Torch versus
NumPy model checks and independently arranged score calculations validate the
adapter without claiming an independent world construction. All original source
failures and corrections remain in the imported receipts. No final test lineage
is selected, exposed or used to choose an interface here.

The composition ruler distinguishes exhaustive static factor assignments, which
commute, from ordered native claim-edit/evidence-repair operations, which need
not commute. Synthetic orthogonal-factor and constant-head controls validate the
measurement but admit no learned reader. The learned composition successor is
blocked by selective-access admission. The expertise successor still requires
a shared inversion population and matched observation-quality conditions; a
fixed-actor production packet must not be renamed as that comparison.

Every successful card writes full receipts for internal landing. Original week
deadlines, closure reserves, four-hour health inspections and final-packet
reporting stay unchanged. The separately failed local-reader canary continues
to block its fifteen local comparison cards. Prepared paid work has no allocation.
