# Stage 10 local autonomous runway

Owner commission: September 13, 2026. Continue local Phase 2 Stage 10 in Gear 2;
Gear 3 is held. This implements the existing study and comparison freeze.
It introduces no new scientific hypothesis, cloud release or delegation.

## Frozen work

The first ScholaWrite bank is already running. A finite native follow-on queue
waits for that controller's terminal output before acquiring the GPU. Five
rotations cover the five available source projects, each held out for evaluation
once, with a different project for development and the other three for training.
Each rotation uses up to twenty pre-ranked released-edit boundaries per project.
The first boundary of every project is excluded from all science roles and only
those discarded boundaries may supply literal pilots. Whole-boundary context
exclusions apply to every strategy and view; documents are never truncated to
fit a reader selectively.

The targets are the next released edit category and location, separately.
Current drafts, strictly earlier drafts and prior process records are three
separate evidence views. All six strategies run on a common eligible cohort:
direct prediction, concrete retrieval, matched direct deliberation, executed
rule hypotheses, procedure-plus-example memory and development-frozen adaptive
effort. Grounded/opaque naming and fixed/confidence-only routing remain controls.
Development labels are opened only after complete development forecasts;
evaluation labels are never used for strategy, threshold or cohort selection.
Repeated folds and views are not additional independent projects. These are
descriptive cross-project comparisons on historically available data. Released
annotations are observed edit types, not writer-stated goals or preferences.

The remaining local model comparison uses the already installed Llama 3.1 8B
profile and frozen original CoAuthor evaluation cohort. It compares direct,
deliberative, executable-rule and storage-matched retrieval/procedure readers,
including the development-selected grounded rival. The second profile must
pass a discarded literal interface pilot. It does not silently replace the
first model or change its saved requests.

A small ArgRewrite continuity anchor predicts the distribution of future
revision purposes once per whole essay and evidence view. That one forecast is
scored over all canonical future units with equal essay weight, while its calls
are charged once. It has separate discarded essays and a training-only prior.
It does not select excerpts using the future target location.

The Ghost reconstruction reader gains the existing adaptive-effort controller
at the actual reserved token budgets. Native execution, training-only memory,
source-case separation, mismatch and invalid-output handling stay intact. The
original opportunity reserve, human common cells, earlier-draft cells and
matched other-writer history intervention all receive complete analysis jobs.
Strategy pairing requires identical public evidence; history intervention uses
its separately verified exact-length replacement and unchanged other evidence.

world is built here and no human handling label is renamed recipient effect.

The study's approximately five-day / forty-to-sixty-five GPU-hour planning range

provides several days of useful automatic work at observed local throughput.
No duplicate runs, artificial delays or recursive refill pad it to seven days.
Queue elapsed time, actual model callback costs, reused historical costs and
agent/setup time are separate quantities. Source projects, constructors, writers

## Execution and recovery

`runners/stage10/local_runway.py` executes the reviewed local module/argument
list serially. Every job has an immutable output guard, source hashes and earlier
dependencies. A failed branch blocks its dependent jobs while independent work
continues. Successful outputs are verified by their full file inventory. An
unowned partial directory or ambiguous GPU ownership refuses instead of
restarting or reclaiming a live job. Sources pinned by the running bank must not
be edited; repairs use a separately inspected continuation after its boundary.
CPU boost stays disabled and AC maximum processor state stays at ninety percent.

The private plan, native PID/creation identity and final produces are recorded
in the Stage 10 implementation handoff. The non-LLM watchdog detects completion,
failure or disappearance; no elapsed-time liveness wake or Stop recursion is
scheduled. Hidden native windows avoid periodic visible command prompts.

The last job assembles all job dispositions, full numerical tables, source
bindings, costs and deterministically selected worked-example candidates into
one private review packet. It never declares a scientific verdict. The operating
agent then inspects complete cells and controls, performs the required
FINDINGS/theory/TODO write-through and delivers one final curator packet. No
intermediate per-artifact scores are reported. No new queue is auto-generated.
