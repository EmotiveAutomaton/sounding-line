# Do AMI speakers with the same native language join each other’s laughter more often?

**Hypothesis.** Do AMI speakers with the same native language join each other’s laughter more often?

**METHOD.** For each metadata-supported pair with laughs from both people, average the two directional shares joined within one second. Regress that share on same native language and both base laugh rates using within-meeting centering, and refit 2,000 meeting-cluster bootstrap draws.

**Found.** The same-language difference in joined laughter is inconclusive in AMI; this does not establish shared background as a marker of shared inference.

The same-minus-different coefficient is 0.00319315 share units, with 95% interval [-0.02160774, 0.02852898], against the frozen 0.02 bar. This uses 745 defined pairs from 131 analytical meetings. The original source frame has 1,038 possible pairs across 171 meetings; absent metadata and undefined no-laugh fractions are counted rather than replaced by zeros.
