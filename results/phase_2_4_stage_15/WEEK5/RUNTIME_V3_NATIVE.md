# RUNTIME V3 NATIVE

**Hypothesis.** Can a long independent verification stop safely and continue without rewriting its original attempt or licensing incomplete evidence?

**METHOD.** Run the actual native supervisor and child through a constructed verification pause, copy its hash-bound checkpoints into a fresh attempt, and complete exact independent arithmetic replay. Separately return false verification and require a failed terminal. Run six targeted copy/refusal checks for tampering, added files, changed scientific settings, a live predecessor and ambiguous terminals.

**Found.** The runtime now preserves verification pauses as authenticated checkpoints and completes only after a full independent replay; false verification still fails.

The original child already refused false verification; its defect was treating a deliberate verifier yield as failure. The successor accepts only the explicit yielded state as PAUSED. The copied predecessor remains byte-identical, all stable output files are authenticated, and the scientific module, inputs and configuration remain fixed. Only the operational draw and wall quanta may change. Native identities and exits, all completed output bindings, and the exact source closure verify. The deliberately false-verification failure remains as expected negative-control evidence. No scientific observations, estimates, or p-values enter this fixture.

**Means.** Bounded uncertainty work can continue from sealed prefixes while retaining the previous attempt and its cost. This validates execution integrity, not any substantive scientific result. The original supervisors and live dispatcher remain pinned; only separately admitted v3 work uses this successor.
