**Hypothesis.** Already verified source records can be reused without changing
their bytes, while the remaining documents receive independent construction and
replay within the existing combined export budget.

**METHOD.** Build a separate source worker over the unchanged occurrence adapter.
Authenticate the completed source and support pilots, retain the exact pilot
prefix, checkpoint each new session, and replay every new session from the raw
source in a fresh process. Validate known answers, immutable reentry, saved-boundary

Run the actual counted native handler on two constructed sessions before corpus
dispatch.

and scientific comparisons remain separately admitted.
