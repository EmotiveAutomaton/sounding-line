# Pinned exporter handler: verified build and timing-pilot admission

**Hypothesis.** The pinned engine exporter can run in its supplied interpreter under a counted, supervised CPU slot, with authenticated inputs and independently reproduced output.
**METHOD.** Exercise source/manifest/cohort refusal and native descendant containment; run a constructed source through the full handler twice in fresh processes; independently check source/output hashes, exact joins and repeat entry. Use the actual exporter and frozen engine with constructed losses before starting the real reader.
**Found.** All 42 targeted checks and the corrected native rehearsal pass. All 90 native pins and 29 terminal artifacts verify. **Means.** The fixed ten-document real-reader timing pilot is admitted and launched. No full-corpus, 100-document signature-support or scientific admission follows.

The importer checks the exact exporter hash, engine commit/source manifest, reader manifest/files, document hashes, provenance and all three coordinate systems. Real execution uses Qwen2.5-0.5B, dynamic int8 linear layers and float32 embeddings, one CPU thread, with ToMpathy's existing Torch 2.9.1+cpu and Transformers 4.57.6 environment. The Sounding Line interpreter's different versions are not substituted. No download, GPU or paid call is used.

Both handler phases run inside native kill-on-close process jobs. The counted supervisor checks RAM, commit, disk, output bytes and the combined wall deadline during execution and verification. One CPU slot remains reserved for the demo. Fragment inputs are retained for later habit analysis; this pilot exports final documents only. Every original word row remains represented, including words outside the selected cohort and unsupported survivors.

The fixed ten-document pilot measures reader cost; it does not satisfy EV2's required 100-document support count. Full admission must charge source preparation and all replay costs alongside the measured reader cost, and retain unsupported counts. No unfinished scientific scores are reported.
