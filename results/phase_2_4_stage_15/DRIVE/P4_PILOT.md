# P4 execution pilot

**Question.** Can the fixed chronological predictive pipeline run on a real eligible recipient before a full dispatch?
**METHOD.** Select the first eligible writer using only frozen chronology and counts, fit the baseline/content alternatives and shuffled control, retain model/feature/split artifacts, and replay saved statistics in a fresh process. Input/output hashes and native exit verify.

**Found.** The complete pilot took 33.29 seconds. Linear extrapolation across 41 eligible recipients is 22.75 minutes; the operational allowance retains a threefold margin. This is execution evidence, with no one-writer population inference. Models remain private.

**Next.** The full route must execute its primary first and only run the writer-offset extension if the packet's positive/marginal branch calls for it. A separate checkpoint-aware implementation is being prepared; this completed pilot does not launch it automatically. [Verified aggregate](P4_PILOT.json).
