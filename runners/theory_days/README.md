# Theory-days CPU runners

Implements the November 6 Stage 15 commission in
`docs/design/stage-15/theory-days/`. No cloud, GPU, theory synthesis or publishing
is performed by these runners. Raw source data and identities remain private.

Use immutable plans, source pins, counted native processes, Windows Job Object
CPU accounting and independent verification. The existing Week 4 runtime is
imported without changing its source; this campaign supplies its own admission
policy and deadline. Design notes must be committed before scientific execution.
Tests use constructed data. Source intake does not compute study outcomes.
