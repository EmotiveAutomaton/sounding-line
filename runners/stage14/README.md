normal priority. No paid readers, cloud dispatch, participant contact or Ghost
modification. Friday October 16, 18:00 PDT is the reporting checkpoint.

budget before dispatch. Handler outputs and failed attempts remain local in `raw/`.

gates. Completion is not admission. Source replay is not independent corroboration.

reader blocks its descendants, not independent data, personal learning or exact work.

README before changing runners. Never edit the sources bound to a running card.

handles terminal alerts and the newly commissioned six-hour health inspection.
